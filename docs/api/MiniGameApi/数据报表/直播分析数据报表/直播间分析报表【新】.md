直播间分析报表接口用于获取直播间的基础分析数据、互动分析数据

数据范围&口径：

1. 仅支持获取投放账户关联的抖音号的直播数据，不限制投放账户和抖音号两者需为同一公司主体
2. 仅支持查询2020年7月1日之后的数据
3. 指标为非实时数据，一般在次日凌晨产出前一天的数据（与直播是否结束无关）

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 客户id |
| start\_time | string | 报表开始时间，格式为%Y-%m-%d %H:%M:%S  默认从7天前开始，仅支持天级别的数据查询，请从0点开始查询，否则返回值为空 |
| end\_time | string | 报表结束时间，格式为%Y-%m-%d %H:%M:%S  默认为今天，最大时间范围为62天 |
| fields | string[] | 指标字段 |
| filtering  必填 | object | 过滤器 |
| room\_ids  条件必填 | number[] | 直播间ID，最多筛选100个直播间ID  返回数据范围为筛选的直播间下营销和自然流量数据，包含直播间的所有账户数据  若不筛选则按照消耗指标倒序返回消耗top10的抖音号 直播间ID和抖音号ID须至少筛选其中一个 |
| aweme\_ids  条件必填 | number[] | 抖音号ID  返回数据范围为筛选的抖音号下全量直播间数据，包括营销和自然流量，包含直播间的所有账户数据，最多支持筛选 10 个抖音号ID  若不筛选则按照消耗指标倒序返回消耗top10的抖音号  直播间ID和抖音号ID须至少筛选其中一个 |
| first\_flow\_category | string | 直播间一级流量来源，可选值:   * `AD` 竞价 * `BRAND` 品牌 * `DOU` DOU+ * `NATURAL` 自然流量 * `OTHER` 其他 |
| order\_field | string | 排序字段 |
| order\_type | string | 排序方式，可选值:    * `ASC` * `DESC`（默认值） |
| page | number | 页码，默认值为1 |
| page\_size | number | 页面大小，默认值为20，最大值为100 |

def build_url(path, query=""):
    # type: (str, str) -> str
    """
    Build request URL
    :param path: Request path
    :param query: Querystring
    :return: Request URL
    """
    scheme, netloc = "https", "api.oceanengine.com"
    return urlunparse((scheme, netloc, path, "", query, ""))
​
def get(json_str):
    # type: (str) -> dict
    """
    Send GET request
    :param json_str: Args in JSON format
    :return: Response in JSON format
    """
    args = json.loads(json_str)
    query_string = urlencode({k: v if isinstance(v, string_types) else json.dumps(v) for k, v in args.items()})
    url = build_url(PATH, query_string)
    headers = {
        "Access-Token": ACCESS_TOKEN,
    }
    rsp = requests.get(url, headers=headers)
    return rsp.json()
