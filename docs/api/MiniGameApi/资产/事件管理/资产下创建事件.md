> 此接口用于在资产下创建单个事件

* 需要先通过【获取投放内容】接口获取要创建的资产ID（asset\_id）
* 需要先通过【获取可创建事件】接口获取到某资产下支持创建的事件ID（event\_id）
* 当资产类型是三方落地页时，同资产同事件支持多种回传方式，但XPATH不能与JSSDK和EXTERNAL\_API同时存在。应用类资产只支持传入一个回传方式。

### 请求方式

POST

### Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Content-Type必填 | string | 请求消息类型，允许值：`application/json` |
| Access-Token必填 | string | 授权Access-Token，获取方法见接口文档【获取Access-Token】 |

### 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id必填 | number | 客户ID |
| asset\_id必填 | number | 资产ID |
| event\_id必填 | number | 事件ID |
| track\_types必填 | string[] | 事件回传方式列表，允许值：`JSSDK` JS埋码 、`EXTERNAL_API` API回传 、`XPATH` XPath圈选、`APPLICATION_API` 应用API 、`APPLICATION_SDK` 应用SDK 、`QUICK_APP_API` 快应用API |

    # type: (str, str) -> str
    """
    Build request URL

        "Content-Type": "application/json",
