### 请求方法

POST

### Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token必填 | string | 授权access\_token，可以通过[【获取Access token】](https://open.oceanengine.com/labels/7/docs/1696710505596940)接口获取 |
| Content-Type必填 | string | 请求消息类型 允许值: `application/json` |

### 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| organization\_id必填 | number | 纵横组织id |
| asset\_id必填 | number | 事件资产id |
| share\_mode必填 | string | 取消共享模式，可选值: `ALL`: 组织下某业务线账户`PART`: 指定账户共享 |
| account\_infos条件必填 | object[] | 取消共享账户信息，一次最多操作10个 当share\_mode="PART"时必填 |
| account\_id | number | 账户id |
| account\_type | string | 账户类型，可选值: `AD` |
| all\_account\_type条件必填 | string[] | 取消共享账户业务线 当share\_mode="ALL"时必填，可选值：: `AD` |
