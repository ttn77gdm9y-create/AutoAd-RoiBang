### 请求方法

GET

### Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token必填 | string | 授权access\_token，可以通过[【获取Access token】](https://open.oceanengine.com/labels/7/docs/1696710505596940)接口获取 |

### 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id必填 | number | 客户ID |
| asset\_id必填 | number | 资产ID |
| download\_url | string | 应用下载链接，当传入download\_url返回该下载链接下的监测链接组；当不传入download\_url只传入asset\_id时，返回所有应用下载链接下的监测链接组 |
| track\_url\_group\_name | string | 监测链接组名称 |
| track\_url\_group\_id | number | 监测链接组ID |
| page | number | 页码 |
| page\_size | number | 分页个数 |

def build_url(path, query=""):
    # type: (str, str) -> str
    """
    Build request URL
    :param path: Request path
    :param query: Querystring
    :return: Request URL
    """
    scheme, netloc = "https", "ad.oceanengine.com"
    return urlunparse((scheme, netloc, path, "", query, ""))
​
def get(json_str):
    # type: (str) -> dict
    """
    Send GET request
    :param json_str: Args in JSON format
    :return: Response in JSON format
    """
    args = json.loads(json_str)
    query_string = urlencode({k: v if isinstance(v, string_types) else json.dumps(v) for k, v in args.items()})
    url = build_url(PATH, query_string)
    headers = {
        "Access-Token": ACCESS_TOKEN,
    }
    rsp = requests.get(url, headers=headers)
    return rsp.json()

    /**

    private static String get(String jsonStr) throws IOException, URISyntaxException {

        URIBuilder ub = new URIBuilder(buildUrl(PATH));
        Map< String, Object > map = mapper.readValue(jsonStr, Map.class);

                .method("GET", null)

        return response.body().string();
    }
