# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 客户ID |
| asset\_type  必填 | string | 资产类型，目前支持THIRD\_EXTERNAL、QUICK\_APP、APP 可选值:    * `APP` 应用类 * `TETRIS_EXTERNAL` 建站落地页 * `THIRD_EXTERNAL` 三方落地页 * `MINI_PROGRAME` 小程序 * `OFFLINE_EVENT` 离线 * `OTHER` 其他 * `QUICK_APP` 快应用 |
| third\_part\_asset | object | 三方落地页资产信息 |
| name | string | 落地页名称，长度限制为`25`，一个字符长度为1 |
| description | string | 落地页描述信息，长度限制为`150`，一个字符长度为1 |
| quick\_app\_asset | object | 快应用资产信息 |
| name  必填 | string | 快应用名称，长度限制为20，一个字符长度为1 |
| package\_name  必填 | string | 快应用包名，长度限制为140 |
| app\_asset | object | 应用信息 |
| name  必填 | string | 应用名称，长度限制为125，一个字符长度为1，IOS、Android应用必填 |
| package\_name  必填 | string | 应用包名，长度限制为140，IOS、Android应用必填 |
| download\_url  必填 | string | 应用下载链接，IOS、Android应用必填 |
| app\_id | number | 应用ID，Android应用必填 |
| package\_id | string | 母包ID，Android应用必填 |
| app\_type  必填 | string | 应用类型，允许值：IOS、Android 可选值:    * `Android` * `IOS` |
| app\_create\_type | string | 应用创建类型，可选值:    * `NORMAL` * `UG`  默认值: `NORMAL` |
| site\_asset | object | 橙子落地页信息 |
| site\_id | number | 橙子建站站点id，橙子落地页必填 |
| site\_name | string | 橙子建站站点名称，橙子落地页必填 |
| mini\_program\_asset | object | 字节小程序资产信息 |
| mini\_program\_id  必填 | string | 字节小程序AppID，需要与资产id后面信息一致 |
| mini\_program\_name  必填 | string | 字节小程序的名称，需要与资产id后面信息一致 |
| instance\_id  必填 | number | 字节小程序资产ID，通过【工具】-【获取字节小程序/小游戏】获取 |
| mini\_program\_type  必填 | string | 小程序类型，目前支持：BYTE\_APP，BYTE\_GAME 可选值:    * `BYTE_APP` 小程序 * `BYTE_GAME` 小游戏 |
