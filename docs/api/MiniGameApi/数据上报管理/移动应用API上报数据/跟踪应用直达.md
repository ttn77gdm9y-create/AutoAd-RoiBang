**1.调起类营销为什么要做转化跟踪**

对于调起类营销而言，使用移动API回传的方式有利于提高调起类营销转化率，降低转化成本，提高跑量速度。可以根据用户在第三方APP的关键行为调整投放群体，将营销投给最可能完成关键操作的用户。

**2.我们如何使用创建计划的时候使用该功能**

在营销目的为“应用”的计划组内可以使用跟踪应用直达，下载方式需要选择落地页方式。

![](https://p6-business-sign.byteadimg.com/tos-cn-i-yvqzo4lhg5/97451c29948c4edc9518bbfdab11ffcd~noop.image?x-expires=1988789558&x-signature=I4plFTCn%2BUmNqCkyjUBmlNsm1Xc%3D)

**3.创建了转化目标，怎么激活转化目标**

在转化列表里头选择检测转化上报，完成下面三个步骤就可以了。1.填写uid，2.获取营销点击数据，3.回传目标用户参数。

![](https://p26-business-sign.byteadimg.com/tos-cn-i-yvqzo4lhg5/ded94953311e4e94b0a2bc99083a725d~noop.image?x-expires=1988789558&x-signature=FzDoQLzDNa9G6n6g0v7GRCFUHvA%3D)

**4.激活过程是否一定需要客户的技术人员参与？**

是的。该对接过程需要客户配合开发，在激活联调过程中，需确认客户能够正常接收用户行为数据，成功匹配转化目标，并成功回传事件。
