## 转化回传鉴权是什么？

「转化回传鉴权」是一个安全性功能，建议有技术能力的客户接入使用，其本质是对数据回传方进行身份认证校验。完成技术对接后，客户可以生成特定密钥，使用密钥作为身份验证完成数据回传，可以有效避免恶意冒名回传请求风险，进一步保障客户的数据安全和数据回传质量。

## 如何完成转化回传鉴权？

> 面向客户：暂只面对已有接入Marketing API能力的客户，且有数据回传验证需求的客户。

### 使用步骤：

秘钥由客户自己生成，并由客户自主分配秘钥的使用范围。

### 技术对接方案：

1. 详细技术开发手册：[转化回传API鉴权接口文档（对外）](https://bytedance.feishu.cn/docs/doccnYlCdHMkamZ6lBw7K5wCSLd#XTeYxo)
2. 鉴权回传步骤： 新增公钥：客户将公钥保存到平台。为确保客户使用了正确的公钥格式和签名算法，在新增公钥时有一步验签的动作，客户使用私钥对指定文本（见下文）签名。 测试鉴权：在新增公钥之后，客户即可对转化回传API的鉴权功能进行测试。鉴权关闭状态下，鉴权失败的转化不会被丢弃，同时返回鉴权失败原因，方便客户调试定位。 开启鉴权：在客户完成代码上线，并确认上线后有成功回传转化，且没有鉴权失败（观察24h以上）之后，可请求“开启鉴权”接口，平台在检查满足条件后开启鉴权。开启鉴权后，鉴权失败的转化数据将被丢弃。

## FAQ

1. 使用转化回传鉴权功能一定要对接Marketing API吗？
2. 回答：是的，因为该功能对接的前提是客户已完成Marketing API对接，可以正常完成Marketing API接口调用，才可以完成批量鉴权功能。
