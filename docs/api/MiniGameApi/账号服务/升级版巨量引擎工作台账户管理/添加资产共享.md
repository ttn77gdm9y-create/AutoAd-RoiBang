# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 账户ID |
| account\_type  必填 | string | 账户类型，允许值：   * `EBP` 企业版组织 |
| auth\_targets  必填 | object[] | 共享信息   * 指定账户ID共享，上限100个ID * 组织下所有账户共享，上限20个ID |
| auth\_target\_type  必填 | string | 共享模式，允许值：   * `ACCOUNT` 共享给账户 * `COMPANY_ALL_ACCOUNT` 共享给主体下所有账户 * `COMPANY_APPKEY_ACCOUNT` 共享给主体下某条业务线下的账户 * `GROUP_ALL_ACCOUNT` 共享给组织下所有账户 * `GROUP_APPKEY_ACCOUNT` 授权给组织下某条业务线下的账户 * `GROUP_DIRECT_ACCOUNT` 共享给升级版组织全部账户 * `GROUP_OVERALL_ACCOUNT` 共享给升级版组织及下属组织全部账户 |
| target\_id  必填 | number | 共享目标账户ID   * 指定账户共享：账户ID * 组织下所有账户共享：普通版组织ID或升级版组织ID |
| sub\_target | string[] | 业务线类型，允许值：   * `AD` 巨量营销 * `QIANCHUAN` 巨量千川 * `LOCAL` 巨量本地推 |
| assets  必填 | object[] | 授权资产范围，上限20 |
| asset\_type  必填 | string | 资产类型，允许值：   * `APPLETS` 小程序 * `BYTED_APPLETS` 字节小程序 * `BYTED_GAME` 字节小游戏 * `DPA` 通用版商品库 * `PRODUCT` 升级版商品 * `WECHAT_GAME` 小游戏 * `APP` 应用 * `HARMONY_APP` 鸿蒙 * `QUICK_APP` 快应用 |
| asset\_scope  必填 | number | 共享资产范围（按照单资产查询或期望查询某个升级版组织下全部资产的共享范围）   * 查询某个资产当前共享范围：传具体资产ID * 查询某个团队或包含下级团队资产的共享范围：传团队id |
| asset\_scope\_type  必填 | string | 查询的资产范围类型（按照单资产查询或期望查询某个升级版组织下全部资产的共享范围），允许值：   * `GROUP_DIRECT_ASSET` 组织直连资产 * `GROUP_OVERALL_ASSET` 组织及子组织全部资产 * `SINGLE_ASSET` 单个资产 |
