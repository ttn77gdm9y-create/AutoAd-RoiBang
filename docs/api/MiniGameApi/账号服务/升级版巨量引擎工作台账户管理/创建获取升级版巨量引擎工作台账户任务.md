<https://api.oceanengine.com/open_api/2/ebp/advertiser/task/create/>
[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1829552494525707)

# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| enterprise\_organization\_id  必填 | number | 升级版巨量引擎工作台ID |
| account\_source  必填 | string | 账户类型，允许值：  * `AD` 巨量营销客户账号 * `LOCAL` 本地推 |

**Python**

```python
# coding=utf-8
import json
import requests
​
from six import string_types
from six.moves.urllib.parse import urlencode, urlunparse  # noqa
​
ACCESS_TOKEN = "xxx"
PATH = "/open_api/2/ebp/advertiser/task/create/"
​
​
def build_url(path, query=""):
    # type: (str, str) -> str
    """
    Build request URL
    :param path: Request path
    :param query: Querystring
    :return: Request URL
    """
    scheme, netloc = "https", "api.oceanengine.com"
    return urlunparse((scheme, netloc, path, "", query, ""))
​
def post(json_str):
    # type: (str) -> dict
    """
    Send POST request
    :param json_str: Args in JSON format
    :return: Response in JSON format
    """
    url = build_url(PATH)
    args = json.loads(json_str)
    headers = {
        "Access-Token": ACCESS_TOKEN,
        "Content-Type": "application/json",
    }
    rsp = requests.post(url, headers=headers, json=args)
    return rsp.json()
    
​
if __name__ == '__main__':
    enterprise_organization_id = ENTERPRISE_ORGANIZATION_ID
    account_source = ACCOUNT_SOURCE
​
    # Args in JSON format
    my_args = "{\"enterprise_organization_id\": \"%s\", \"account_source\": \"%s\"}" % (enterprise_organization_id, account_source)
    print(post(my_args))
```
