### 请求方法

GET

### 请求Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token 必填 | string | 授权access-token，获取方法见接口文档[【获取Access-Token】](https://open.oceanengine.com/labels/7/docs/1696710505596940) |

### 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 客户ID/代理商ID  注意：代理商仅支持AD、星图，暂不支持本地推代理商 |
| start\_date | string | 开始时间，格式YYYY-MM-DD，默认当前年份的1月1日 |
| end\_date | string | 结束时间，格式YYYY-MM-DD，默认为今天，起止时间间隔不能超过一年。 |
| page | number | 页码. 默认值: `1`，注意：page\*page\_size不可大于`10000` |
| page\_size | number | 页面数据量. 默认值: `10` |
| account\_type | string | 账户业务类型，可选值:   * `AD` AD客户（默认） * `LOCAL` 本地推 * `STAR` 星图 |
