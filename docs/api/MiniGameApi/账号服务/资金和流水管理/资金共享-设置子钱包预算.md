# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 鉴权账户(旧版巨量引擎工作台传bp\_id，代理商传agent\_id) |
| account\_type  必填 | string | 鉴权账户类型 可选值:    * `AGENT` 代理 * `旧版巨量引擎工作台` 旧版巨量引擎工作台 |
| sub\_wallet\_id  必填 | number | 子钱包ID |
| effective\_mode  必填 | string | 预算生效模式：0：立即生效，1：次日生效 可选值:    * `IMMEDIATE` 立即生效 * `NEXT_DAY` 次日生效 |
| budget  必填 | object | 预算信息 |
| budget\_mode  必填 | string | 预算模式：-1: 不限, 0: 日预算 可选值:    * `DAY` 日预算 * `INFINITE` 不限预算 |
| budget | number | 预算金额，单位：元。需要介于3,000~10,000,000元之间（不限预算模式下不传） |
