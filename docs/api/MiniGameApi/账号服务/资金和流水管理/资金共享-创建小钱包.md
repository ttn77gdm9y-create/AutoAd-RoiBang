# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 账户id，BP传bp\_id，AGENT传agent\_id |
| account\_type  必填 | string | 账户类型，支持BP与AGENT 可选值:    * `AGENT` 代理 * `BP` BP |
| wallet\_id  必填 | number | 钱包 id，调用获取唯一操作id接口生成，以此确保唯一 |
| wallet\_name  必填 | string | 钱包名称, 长度不超过 255 |
| wallet\_description | string | 钱包描述，不填为空 |
| wallet\_label | string[] | 钱包标签，不填为空，最多 10 个，单个标签长度不超过 10 |
| main\_wallet\_id  必填 | number | 所属大钱包 id |
| shared\_range  必填 | object | 共享范围 |
| account\_platform\_list  必填 | string[] | 业务线范围 可选值:    * `AD` 巨量营销 * `ECP` 巨量千川 * `LOCAL_ADS` 巨量本地推 |
