# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 鉴权账户鉴权账户(旧版巨量引擎工作台传bp\_id，代理商传agent\_id) |
| account\_type  必填 | string | 鉴权账户类型 可选值:    * `AGENT` 代理 * `旧版巨量引擎工作台` 旧版巨量引擎工作台 |
| rule  必填 | object | 钱包盯盘预警规则 |
| wallet\_id  必填 | number | 子钱包ID |
| balance\_alert\_rules  必填 | object[] | 余额预警规则组(没有传空list) |
| threshold  必填 | number | 阈值（单位：元） |
| level  必填 | string | 预警级别：0：S级，1：A级，2：B级 可选值:    * `A_LEVEL` A级通知 * `B_LEVEL` B级通知 * `S_LEVEL` S级通知 |
| budget\_usage\_alert\_rules  必填 | object[] | 预算使用率预警规则组(没有传空list) |
| threshold  必填 | number | 阈值（单位：%），只能填30/50/80/100 |
| level  必填 | string | 预警级别：0：S级，1：A级，2：B级 可选值:    * `A_LEVEL` A级通知 * `B_LEVEL` B级通知 * `S_LEVEL` S级通知 |
| budget\_alert\_rules  必填 | object[] | 预算剩余预警规则组(没有传空list) |
| threshold  必填 | number | 阈值（单位：元） |
| level  必填 | string | 预警级别：0：S级，1：A级，2：B级 可选值:    * `A_LEVEL` A级通知 * `B_LEVEL` B级通知 * `S_LEVEL` S级通知 |
| alert\_emails | string[] | 预警通知邮箱(最多5条) |
