# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 账户ID，对于巨量AD、千川、本地推是客户ID，对于代理商是代理商ID |
| account\_type  必填 | string | 账户类型 可选值:   * `AD` 巨量客户 * `AGENT` 代理 * `LOCAL` 本地推客户 |
| shared\_wallet\_id  必填 | number | 共享钱包id |
| start\_date | string | 开始时间，格式YYYY-MM-DD，默认为当前年份的1月1日 |
| end\_date | string | 结束时间，格式YYYY-MM-DD，默认为今天，起止时间间隔不能超过一年。 |
| page | number | 页码；默认为1；注意：page\*page\_size不可大于10000 |
| page\_size | number | 页面大小；默认为10 |
