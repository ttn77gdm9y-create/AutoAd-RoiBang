POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| agent\_ids  必填 | number[] | 代理商ID |
| customer\_id\_list | number[] | 客户ID列表，鉴权使用 |
| statement\_serial  必填 | string | 结算单编号 |
| rebate\_item\_list | object[] | 差额返点编号、金额集合 |
| rebate\_serial | string | 返点编号 |
| apply\_amount | double | 返点申请金额 |
| invoice\_type  必填 | string | 开票类型 可选值:   * `GENERAL` 增值税普通发票 * `SPECIAL` 增值税专用发票 * `E_GENERAL` 增值税电子普通发票 * `E_SPECIAL` 增值税电子专用发票 * `ALL_E_GENERAL` 电子发票（普通发票） * `ALL_E_SPECIAL` 电子发票（增值税专用发票） |
| unprintable\_remark | string | 非打印备注 |
| customer\_subject\_name  必填 | string | 开票客户名称 |
| customer\_tax\_no  必填 | string | 纳税人识别号 |
| customer\_address | string | 企业注册地址 |
| customer\_phone | string | 企业注册电话 |
| customer\_bank | string | 企业开户银行 |
| customer\_bank\_account | string | 企业银行账号 |
| invoice\_bill\_list  必填 | object[] | 发票票据列表 |
| invoice\_bill\_project\_list  必填 | object[] | 开票票据项目列表 |
| invoice\_project\_name  必填 | string | 开票项目名称 |
| apply\_amount  必填 | double | 开票项目金额 |
| specifications | string | 规则型号 |
| unit | string | 单位 |
| remark | string | 打印备注 |
| select\_address\_and\_phone | bool | 数电发票，是否勾选企业注册地址、电话 |
| select\_bank\_and\_account | bool | 数电发票，是否勾选开户行、开户账号 |
| customer\_email  必填 | string | 客户邮箱 |
| customer\_sms\_phone | string | 客户短信电话 |
