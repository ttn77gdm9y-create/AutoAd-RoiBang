# 请求方法

GET

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 鉴权账户id |
| account\_type  必填 | string | 鉴权账户类型 可选值:   * `AD` 巨量客户 * `AGENT` 代理 * `LOCAL` 本地推客户 |
| biz\_request\_no  必填 | string | 请求id，推荐uuid，方便请求链路对齐 |
| query\_begin\_time  必填 | string | 查询开始时间(转账创建时间) yyyy-MM-dd HH:mm:ss |
| query\_end\_time  必填 | string | 查询结束时间(转账创建时间) yyyy-MM-dd HH:mm:ss |
| query\_wallet\_id\_list  必填 | number[] | 需要查询的大小钱包id，加款方与减款方都需要包含在内 |
| payee\_id | number | 加款方id，可选，需要包含在query\_wallet\_id\_list |
| remitter\_id | number | 减款方id，可选，需要包含在query\_wallet\_id\_list |
| page\_info  必填 | object | 分页信息 |
| page\_size  必填 | number | 分页大小，范围：1-100 |
| page\_num  必填 | number | 页码，从1开始，仅支持page\_size \* page\_num < 1w的深度分页 |
