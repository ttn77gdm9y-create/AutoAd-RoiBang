# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| cc\_account\_id  必填 | number | 鉴权账户：支持客户投放账户、巨量引擎工作台账户、升级版巨量引擎工作台账户、ADX账户 |
| account\_id  必填 | number | 待充值的投放账户 |
| platform  必填 | string | 业务线 可选值:    * `AD` 巨量营销 * `DOU_JIA` 抖+ * `DOU_JIA_UPGRADE` 抖+升级 * `NATIVE_LIFE_AD` 巨量本地推 * `QIANCHUAN` 千川 |
| request\_id  必填 | string | 唯一请求参数 |
| charge\_type  必填 | string | 充值类型 可选值:    * `CREDIT` 授信 * `GRANT` 赠款 * `PRELOAN` 预借款 * `PREPAY` 预付 * `REBATE` 返点 |
| charge\_source  必填 | string | 充值来源 可选值:    * `AUTO_CHARGE` 付款码充值 * `CREDIT_CHARGE` 授信充值 * `DAREN_COMMISSION` 达人佣金充值 * `GOODS_TRANSFER` 货款充值 * `MOBILE_CHARGE` 移动充值 * `ONLINE_CHARGE` 在线充值 |
| caller  必填 | string | 请求方 可选值:    * `MAPI` MAPI |

def build_url(path, query=""):
    # type: (str, str) -> str
    """
    Build request URL
    :param path: Request path
    :param query: Querystring
    :return: Request URL
    """
    scheme, netloc = "https", "api.oceanengine.com"
    return urlunparse((scheme, netloc, path, "", query, ""))
​
def get(json_str):
    # type: (str) -> dict
    """
    Send GET request
    :param json_str: Args in JSON format
    :return: Response in JSON format
    """
    args = json.loads(json_str)
    query_string = urlencode({k: v if isinstance(v, string_types) else json.dumps(v) for k, v in args.items()})
    url = build_url(PATH, query_string)
    headers = {
        "Access-Token": ACCESS_TOKEN,
    }
    rsp = requests.get(url, headers=headers)
    return rsp.json()

| Code | Message | 解决方案 |
| --- | --- | --- |
| 40000 | 当前投放账户挂接代理，请联系对应代理商进行转账加款 | 请先参考报错信息自行排查 |
| 40000 | 账户尚未完成对公验证，无法充值，请前往认证中心完成对公验证 | 请先参考报错信息自行排查 |
