# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 鉴权账户：巨量引擎工作台账户、升级版巨量引擎工作台账户 |
| charge\_target\_id  必填 | number | 钱包ID |
| charge\_target\_type  必填 | string | 充值对象类型 可选值:    * `WALLET` 钱包 |
| platform  必填 | string | 业务线 可选值:    * `AD` 巨量营销 * `DOU_JIA` 抖+ * `DOU_JIA_UPGRADE` 抖+升级 * `NATIVE_LIFE_AD` 巨量本地推 * `QIANCHUAN` 千川 |
| request\_id  必填 | string | 唯一请求ID |
| charge\_amount  必填 | number | 充值金额 |
| delivery\_type  必填 | string | 投放方式 可选值:    * `BIDDING` 竞价 * `BRAND` 品牌 * `GENERAL` 通用 |
| caller  必填 | string | 请求方ID 可选值:    * `MAPI` MAPI |
