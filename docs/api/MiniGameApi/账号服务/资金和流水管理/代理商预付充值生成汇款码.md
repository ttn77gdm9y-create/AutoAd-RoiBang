# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| agent\_id  必填 | number | 代理商账号ID |
| caller\_request\_id  必填 | string | 充值请求唯一ID |
| charge\_amount  必填 | number | 充值金额，单位为分（即实际金额\*100） |
| contract\_info  必填 | object | 合同信息 |
| contract\_id  必填 | number | 合同ID |
| delivery\_type  必填 | string | 资金池投放方式 可选值:    * `BIDDING` 竞价 * `BRAND` 品牌 * `GENERAL` 通用 |
| risk\_info | string | 风控信息，至少需要包含device\_id和ip的json字符串，例子：{"ip": xxx, "device\_id": xxx} |
