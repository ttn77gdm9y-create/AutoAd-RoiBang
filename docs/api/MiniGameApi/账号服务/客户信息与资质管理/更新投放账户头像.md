本接口用于更新投放账户头像，使用路径如下：

1. 调用「获取投放账户头像ID」接口获取头像的image\_id
2. 调用本接口完成账户头像的更新

详情

支持

权限点及应用类型

应用类型:  自研投放应用-客户/代理商、提供第三方服务-客户/代理商

接入能力范围:  巨量 PC

支持的账户类型

客户投放账户

# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 投放账户ID |
| image\_id  必填 | string | 账户头像id，例：web.business.image/201910225d0d5a39ae2e246645b486  您可调用「[获取投放账户头像ID](https://open.oceanengine.com/labels/34/docs/1794039016601604)」接口获取头像的image\_id   * 格式：jpg/jpeg/png/bmp * 大小：<=5M * 像素：<=300\*300 |
| source\_info | string | 品牌名称 |
