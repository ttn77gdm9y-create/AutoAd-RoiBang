获取客户资质信息，资质分为描述，营业执照，开户资质，投放资质。不同类型的资质有不同的字段，具体字段见下表。

【注意】本接口不再维护，建议使用「[获取投放资质（新版）](https://open.oceanengine.com/labels/34/docs/1761500990156815)」接口

关键信息

详情

是否支持SDK

支持

权限点及应用类型

了解如何 [申请授权&生成授权](https://open.oceanengine.com/labels/7/docs/1803016515293203?origin=metadata)

权限点:  账号服务-客户信息与资质管理-获取客户信息与资质

应用类型:  自研投放应用-客户/代理商、提供第三方服务-客户/代理商

接入能力范围:  巨量 PC

支持的账户类型

客户投放账户

##### 应答字段

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| code | number | 返回码,详见[【附录-返回码】](https://open.oceanengine.com/labels/7/docs/1696710760866831) |
| message | string | 返回信息，详见[【附录-返回码】](https://open.oceanengine.com/labels/7/docs/1696710760866831) |
| request\_id | string | 请求日志id |
| data | object | json返回值 |
| list | list | 资质列表 |
| qualification\_id | number | 资质id |
| qualification\_type | number | 投放资质类型 1：肖像、商标或其他授权 2: 专利证明 3: 商标证 4: 营销内容中的数据证明 5: 质检报告 |
| picture\_preview\_url | string | 投放资质预览url |
| status | number | 状态 0: 待提交 1: 待审核 2: 审核中 3: 审核通过 4: 审核拒绝 |
| reject\_reason | string | 审核原因 |
| audit\_time | string | 审核时间，形如 `yyyy-MM-dd HH:mm:ss` |
| image\_list | object[] | 资质图片列表 |
| attachment\_id | number | 附件id |
| image\_url | string | 图片预览地址 |
