通过此接口，用户可以批量上传投放资质。

【注意】本接口不再维护，请使用【[上传/更新投放资质（新版）](https://open.oceanengine.com/labels/7/docs/1761501324513352)】接口

* 此接口上传的是投放资质，如需账户主体资质请调用[【上传主体资质（新版）】](https://open.oceanengine.com/labels/7/docs/1743294661429259)接口
* 该接口不支持返回投放资质部分成功部分失败的报错信息，所以失败后需要重新全量上传后再进行审核

##### 请求方法

POST

##### 请求Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Content-Type 必填 | string | 请求消息类型，允许值：`application/json` |
| Access-Token 必填 | string | 授权access-token，获取方法见接口文档[【获取Access-Token】](https://open.oceanengine.com/labels/7/docs/1696710505596940) |

##### 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id 必填 | number | 客户ID |
| qualification\_type 必填 | string | 资质类型，详见[【附录-资质类型】](https://ad.oceanengine.com/openapi/doc/index.html?id=1696710760171535#custom-anchor-广告主资质类型).允许值: `"QUALIFICATION_AD"` |
| qualifications 必填 | list | 资质列表 min>=1 && max<=50 |
| qualification\_img\_id 必填 | string | 资质图片id，通过【[上传资质图片](https://ad.oceanengine.com/openapi/doc/index.html?id=1696710599659532)】获得（需指定 upload\_to 为 AD） |
| ad\_qualification\_type 必填 | string | 资质图片类型 AUTHORIZATION 肖像、商标或其他授权 CERTIFY 专利证明 TRADEMARK\_CERT 商标证 AD\_DATA\_CERT 营销内容中的数据证明 INSPECT\_REPORT 质检报告 |
