通过此接口，用户可以按照一定方式上传符合格式的客户投放资质、主体资质相关图片，例如营业执照等，接口会返回"code\_0"和"message\_OK"，代表上传成功

> 图片格式：jpg、jpeg、png、bmp、gif，大小2M内

此接口上传的是资质图片，如需上传素材图片请调用【[上传营销图片](https://open.oceanengine.com/labels/7/docs/1696710600176640)】接口！

### 请求方法

POST

### 请求Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Content-Type 必填 | string | 请求消息类型，允许值：`multipart/form-data` |
| Access-Token 必填 | string | 授权access-token，获取方法见接口文档[【获取Access-Token】](https://open.oceanengine.com/labels/7/docs/1696710505596940) |

### 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id 必填 | number | 客户ID |
| upload\_type 必填 | string | 图片上传方式 默认值：`UPLOAD_BY_FILE`允许值：`UPLOAD_BY_FILE`、`UPLOAD_BY_URL` |
| image\_signature 条件必填 | string | 图片的md5值(用于服务端校验)，upload\_type为`UPLOAD_BY_FILE`必填 |
| image\_file 条件必填 | file | 图片文件,upload\_type为`UPLOAD_BY_FILE`必填 格式: jpg、jpeg、png、bmp、gif, 大小2M内 |
| image\_url 条件必填 | string | 图片url地址，如http://xxx.xxx，upload\_type为`UPLOAD_BY_URL`必填 |
| upload\_to 必填 | string | 调用上传资质 默认值：`CG`允许值：`CG`：客户资质接口、`AD`：投放资质接口 |

def upload_advertiser_image():
    import requests
    open_api_url_prefix = "https://ad.oceanengine.com/open_api/"
    uri = "2/file/image/advertiser/"
    url = open_api_url_prefix + uri
    files = {
    "image_file": open("/Users/Documents/071304.png", "rb"),
    }
    data = {
    "advertiser_id": 0,
    "upload_type": "UPLOAD_BY_FILE",
    "image_signature": "xxx",
    }
    headers = {"Access-Token": "xxx"}
    rsp = requests.post(url, data = data, files=files, headers=headers)
    rsp_data = rsp.json()
    print(rsp_data)
