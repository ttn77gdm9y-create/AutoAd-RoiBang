# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token必填 | string | 授权access\_token，可以通过[【获取Access token】](https://open.oceanengine.com/labels/7/docs/1696710505596940)接口获取 |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id必填 | number | 客户 |
| filter | object | 过滤条件 |
| template\_ids | number[] | 模板ID数组，数量限制`100` |
| site\_ids | number[] | 站点ID，可通过[【橙子建站】](https://www.chengzijianzhan.com/)平台或[【获取橙子建站站点列表】](https://open.oceanengine.com/doc/index.html?key=ad&type=api&id=1696710620579852#item-link-%E8%AF%B7%E6%B1%82%E5%9C%B0%E5%9D%80)获取 |
| keyword\_of\_name | string | 模板名称关键词 |
| page | number | 页码，默认值是`1`，范围page >=1 |
| page\_size | number | 页面大小，默认值是`20`，范围`1~100` |
