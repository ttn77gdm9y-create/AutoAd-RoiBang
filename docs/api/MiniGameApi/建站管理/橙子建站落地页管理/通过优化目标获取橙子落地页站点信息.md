本接口支持获取优化目标关联橙子建站站点列表，方便您通过API创编营销

注意：本接口暂不支持区分橙子落地页是账户下自建的还是被共享的，您可通过以下方式进行区分：

* 步骤1：通过【[获取橙子建站站点列表](https://open.oceanengine.com/labels/34/docs/1696710620579852?origin=left_nav)】查询账户下全量站点信息，该接口支持区分站点来源（账户创建站点 or 被共享站点）
* 步骤2：调用本接口，查询external\_action、deep\_external\_action关联的橙子落地页，根据步骤1获取结果在本地自行区分
