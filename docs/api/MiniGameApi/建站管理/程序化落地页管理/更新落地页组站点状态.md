### 请求方法

POST

### Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token必填 | string | 授权access\_token，可以通过[【获取Access token】](https://ad.oceanengine.com/openapi/doc/index.html?id=538)接口获取 |
| Content-Type必填 | string | 请求消息类型 允许值: `"application/json"` |

### 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id必填 | number | 客户ID |
| group\_id必填 | number | 落地页组 ID |
| data必填 | object[] | 操作站点 |
| member\_id必填 | number | 成员 ID，即站点在落地页组中的唯一标识 |
| site\_opt\_status必填 | string | 站点启用状态，详见[【附录-枚举值】](https://ad.oceanengine.com/openapi/doc/index.html?id=1696710760171535)，可选值: `SITE_OPT_STATUS_DISABLE`,`SITE_OPT_STATUS_ENABLE` |
