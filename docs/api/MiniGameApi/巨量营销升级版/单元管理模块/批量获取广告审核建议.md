# Header

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 客户ID |
| promotion\_ids  必填 | number[] | 营销id列表，list长度1-10 |
| delivery\_mode | string | 投放模式`已废弃`，传入无效。允许值：   * `MANUAL` 手动投放（默认值） * `PROCEDURAL` 自动投放 |
| need\_material\_lego\_mid | bool | 是否需要返回素材legoMid，默认为false |

    /**

    global $ACCESS_TOKEN, $PATH;
