**本接口支持删除一条营销下存在的素材，请注意**

* 仅支持删除「巨量营销」账户下的营销素材
* 仅支持删除客户在营销下添加的图片、视频、图文素材
* 不支持删除营销下「已删除」的素材，如传入的material\_id在营销下的素材状态为已删除，调用本接口会报错“营销下不存在素材”
* 不支持将营销下素材全部删除，当营销下仅剩下1个素材时，再调用接口删除素材会报错
