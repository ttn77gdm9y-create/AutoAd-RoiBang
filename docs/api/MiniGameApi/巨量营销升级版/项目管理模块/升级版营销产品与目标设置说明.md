# 一、 概念说明

* **营销产品：**即客户在巨量引擎投放的对象,对于电商行业业可能是某件衣服,下载行业可能是某个App或者小程序,网服行业可能是某部小说,线索行业可能是婚纱摄影影套餐/培训课程服务等。

![](https://p26-business-sign.byteadimg.com/tos-cn-i-yvqzo4lhg5/7fbf5ae0576c4b2bbc89d58c3850c8d1~noop.image?rk3s=d3394059&x-expires=2046834062&x-signature=SyF8TZa5MRNknu9ndv6EG%2Fe0mnE%3D)

* **商品**：

* 由商品库（原行业产品中心）来承载营销产品的表达包含非下载行业（如教育/金融）和少部分下载行业（如小说/短剧）
* 客户可以在工作台的商品库（原行业产品中心）创建商品（原产品）并在投放时使用
* 特别说明:对于部分投放账户，因其他项目要求必须关联关商品进行投放的（如使用ubmax、医疗机构、医疗器械等行业客户）在投放产品模块仅支持选择「商品」选项

* **投放载体**

* 「投放载体」是客户使用「商品」投放时增加的选项。因营销产品中的「商品」无法直接投放，需关联对应载体才可以完成投放诉求的表达，这个投放载体在应用场景下可能是某个APP，在小程序场景下可能是某个小程序或小游戏，在原生场景下可能是抖音号或落地页。

# FAQ

1. **创编时营销产品的设置不一样,对投放会有影响吗?**

* 您好，本次项目创编页面的升级仅调整创编设置结构，将「关联产品」、「投放内容与目标」两个模块融合为「营销产品与目标」，目的是帮助客户更准确表达投放诉求，不影响营销效果。
