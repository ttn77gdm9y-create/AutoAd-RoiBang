# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 投放账户id |
| data  必填 | object[] | 批量修改投放时间，限制最多批量修改10个项目 |
| project\_id  必填 | number | 项目ID |
| schedule\_type  必填 | string | 投放时间类型，允许值：   * `SCHEDULE_FROM_NOW`从今天起长期投放（默认） * `SCHEDULE_START_END`结束日期   注：搜索下极速智投（原周期稳投）项目，若项目设置的原投放时间类型为7日稳投，不支持在批量更新接口中修改为其他投放时间类型 |
| end\_time  条件必填 | number | 结束的投放时间，当schedule\_type 为`SCHEDULE_START_END`时必填  时间必须到秒级，否则会报错 |
