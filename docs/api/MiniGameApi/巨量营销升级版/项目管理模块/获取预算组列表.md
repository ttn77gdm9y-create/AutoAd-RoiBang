# 请求方法

GET

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 客户id |
| filtering | object | 过滤条件 |
| budget\_group\_id\_list | number[] | 预算组ID列表，一次最多传入200个ID |
| budget\_group\_keyword | string | 预算组名称模糊搜索关键字 |
| delivery\_type | string | 投放类型 可选值:   * `MANUAL` 手动投放模式 * `PROCEDURAL` 自动投放模式 |
| ad\_type | string | 营销类型 可选值:   * `ALL` 通投 * `SEARCH` 搜索 |
| budget\_group\_status\_first | string | 预算组聚合一级状态 可选值:   * `DELETED` 已删除 * `ENABLE` 启用中 * `UNDELIVERIED` 未投放 |
| budget\_group\_status\_second | string | 预算组聚合二级状态 可选值:   * `ACCOUNT_EXCEEDED` 账户超出预算 * `GROUP_EXCEEDED` 预算组超出预算 |
| statistics\_time | object | 统计时间范围 |
| start\_time | string | 开始时间，格式：yyyy-mm-dd HH:MM:SS  用于查询一段时间内指定预算组的消耗数据 |
| end\_time | string | 结束时间，格式：yyyy-mm-dd HH:MM:SS，默认为当前时间  用于查询一段时间内指定预算组的消耗数据 |
| page  必填 | number | 页数，默认值：`1`，page范围为[1,99999] |
| page\_size  必填 | number | 页面大小默认值：`10`，page\_size范围为[1,100] |
