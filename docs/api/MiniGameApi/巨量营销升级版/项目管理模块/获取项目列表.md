| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id必填 | number | 投放账户id |

| filtering | object | 过滤条件，若此字段不传，或传空则视为无限制条件 |
| ids | number[] | 按项目ID过滤，范围为1-100 |

| app\_promotion\_type | string | 子目标，允许值：  `DOWNLOAD` 应用下载、`LAUNCH` 应用调用、`RESERVE` 预约下载 |
| marketing\_goal | string | 营销场景，允许值：`VIDEO_AND_IMAGE` 短视频/图片、`LIVE`直播 |
| ad\_type | string | 营销类型，允许值：`ALL` 所有营销，`SEARCH` 搜索 |
| name | string | 项目名称，长度是1-50个字  （两个英文字符占1个字，该字段采取模糊查询的方式。） |
| status | string | 项目状态过滤，  注意：此参数已不再维护，请您使用下方的status\_first、status\_second    允许值： `PROJECT_STATUS_ENABLE` 启用 `PROJECT_STATUS_DISABLE` 暂停 `PROJECT_STATUS_DELETE` 删除 `PROJECT_STATUS_ALL` 所有包含已删除 `PROJECT_STATUS_NOT_DELETE` 所有不包含已删除 `PROJECT_STATUS_BUDGET_EXCEED` 项目超出预算 `PROJECT_STATUS_BUDGET_PRE_OFFLINE_BUDGET` 项目接近预算 `PROJECT_STATUS_NOT_START` 未达投放时间 `PROJECT_STATUS_DONE` 已完成 `PROJECT_STATUS_NO_SCHEDULE` 不在投放时段 |
| status\_first | string | 项目一级状态过滤，允许值：  `PROJECT_STATUS_DELETE`已删除  `PROJECT_STATUS_DONE`已完成  `PROJECT_STATUS_DISABLE`未投放  `PROJECT_STATUS_ENABLE`启用中  不传默认返回不限（不含已删除） |
| status\_second | string | 项目二级状态过滤，允许值：  `PROJECT_STATUS_STOP` 已暂停  `PROJECT_STATUS_BUDGET_EXCEED` 项目超出预算  `PROJECT_STATUS_NOT_START` 未达投放时间  `PROJECT_STATUS_NO_SCHEDULE` 不在投放时段  `PROJECT_STATUS_BUDGET_GROUP_OFFLINE_BUDGET` 预算组超出预算（新增）  当status\_first = `PROJECT_STATUS_DISABLE`时传入有效  `PROJECT_STATUS_REACH_DAILY_DELIVERY` 未投放-已达每日投放时长 |
| project\_create\_time | string | 项目创建时间，格式yyyy-mm-dd，表示过滤出当天创建的项目 |
| project\_modify\_time | string | 项目更新时间，格式yyyy-mm-dd，表示过滤出当天更新的项目 |
| project\_modify\_start\_time | string | 项目更新开始时间，该筛选支持您细分到秒级查询一段时间内修改过的项目信息  格式yyyy-mm-dd hh:mm:ss    注意   1. 必须与结束时间project\_modify\_end\_time结合使用，注意时间跨度不能超过30天 2. 开始时间<=结束时间 3. 可以与project\_modify\_time同时使用，但不太有必要。直接使用project\_modify\_start\_time、project\_modify\_end\_time组合筛选即可 |
| project\_modify\_end\_time | string | 项目更新结束时间，该筛选支持您细分到秒级查询一段时间内修改过的项目信息  格式yyyy-mm-dd hh:mm:ss    注意   1. 必须与开始时间project\_modify\_start\_time结合使用，注意时间跨度不能超过30天 2. 开始时间<=结束时间 3. 可以与project\_modify\_time同时使用，但不太有必要。直接使用project\_modify\_start\_time、project\_modify\_end\_time组合筛选即可 |
| pricing | string | 按计费方式过滤 |
| inventory\_type | string | 按首选位置过滤，允许值 `INVENTORY_FEED` 今日头条 `INVENTORY_VIDEO_FEED` 西瓜视频 `INVENTORY_AWEME_FEED` 抖音短视频 `INVENTORY_TOMATO_NOVEL` 番茄小说 `INVENTORY_UNION_SLOT` 穿山甲 `UNION_BOUTIQUE_GAME` ohayoo精品游戏  `INVENTORY_HOMED_AGGREGATE` 住小帮  `INVENTORY_SEARCH` 搜索投放版位 |
| platform | string | 按平台过滤，允许值：`IOS`、`ANDROID`、`HARMONY` |
| budget\_group\_id | number | 按预算组ID过滤，仅允许传入1个，该功能白名单开放，如需使用请联系销售  您需要首先通过「[创建预算组](https://open.oceanengine.com/labels/34/docs/1780159359081540)」/「[获取预算组列表](https://open.oceanengine.com/labels/34/docs/1780644067911818)」接口拿到此id |
| blue\_flow\_package\_setting | string | 是否开启蓝海流量投放过滤，允许值：ON、OFF |
| star\_delivery\_type | string | 是否为星广联投项目  `STAR_DELIVERY` 星广联投项目  `NOT_STAR_DELIVERY` 非星广联投项目 |
| star\_auto\_delivery\_switch | string | 星广联投全自动化开关，枚举值：  `ON` 开启  `OFF` 关闭    注意：筛选全自动化项目时，筛选条件不需要设置star\_delivery\_type参数 |
| page | number | 页数默认值：`1`，page范围为[1,99999] |
| page\_size | number | 页面大小默认值：`10`，page\_size范围为[1,100] |
