# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 客户ID |
| material\_type  必填 | string | 素材类型 可选值:    * 直玩素材 `STRAIGHT_PLAYABLE` * 试玩素材 `PLAYABLE_NEW` |
| filtering | object | 可选过滤参数 |
| material\_ids | number[] | 素材ID列表 |
| app\_material\_ids | number[] | 试玩/直玩包Material\_id列表 |
| keyword | string | 试玩/直玩素材查询，可通过素材名称/素材ID进行查询 |
| signatures | string[] | 素材MD5值 |
| start\_time | string | 根据素材上传时间进行过滤的起始时间，与end\_time搭配使用  格式：yyyy-mm-dd hh:mm:ss |
| end\_time | string | 根据素材上传时间进行过滤的截止时间，与end\_time搭配使用  格式：yyyy-mm-dd hh:mm:ss |
| status | string | 素材状态，枚举值：  `ONLINE` 素材在线  `OFFLINE` 已下线 |
| audit\_status | string | 审核状态，枚举值：  `STATUS_CONFIRMING` 审核中  `STATUS_CONFIRMED`已通过  `STATUS_CONFIRM_FAIL` 已拒绝 |
| app\_ids | string[] | 直玩-小游戏app\_id（仅直玩素材类型支持） |
| page\_size | number | 分页大小（默认为20） |
| page | number | 页码（默认为1） |
