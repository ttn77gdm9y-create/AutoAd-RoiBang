# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `multipart/form-data` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 客户ID |
| upload\_type  必填 | string | 音频上传方式 ，允许值：   * `UPLOAD_BY_FILE` 文件上传（默认值） * `UPLOAD_BY_URL` 网址上传 |
| audio\_signature  条件必填 | string | 音频的md5值(用于服务端校验)  upload\_type为UPLOAD\_BY\_FILE时必填 |
| audio\_file  条件必填 | file | 音频文件，upload\_type为UPLOAD\_BY\_FILE时必填  允许格式：m4a、mp3  文件大小：≤20M |
| audio\_url  条件必填 | string | 音频url地址，如<http://xxx.xxx>，upload\_type为UPLOAD\_BY\_URL必填 |

# 业务错误码

仅披露当前接口高频的参数校验报错，更多常见报错详见[「返回码」](https://open.oceanengine.com/labels/34/docs/1696710760866831)文档

| Code | Message | 解决方案 |
| --- | --- | --- |
| 400172 | 解析文件失败，请检查传入的素材url/文件是否正确 | 排查建议：① 如您在上传视频，url上传方式仅支持连山url并且url可通过浏览器访问，格式如：https://xxxxxx.volces.com/xxxxx，接入指南详见：https://ad.oceanengine.com/cloud/doc/1756427622851659；② 如您在上传图片，url必须可通过浏览器访问，请自查url格式或采用文件上传解决问题 |
| 400177 | 文件上传异常，请检查视频url/文件是否正确 | 如果您在上传视频，该报错是因为您传入的视频url错误，系统找不到/无法访问这个URL。有2个排查方向：① url上传方式仅支持连山url并且url可通过浏览器访问；② 连山配置有误，TOS和VPC的区域务必选择华北（北京），否则无法内网上传。更多配置规则可参考：https://ad.oceanengine.com/cloud/doc/1756427622851659 |
