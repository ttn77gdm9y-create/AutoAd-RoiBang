# 应答字段

| message | string | 返回信息,详见[【附录-返回码】](https://open.oceanengine.com/labels/7/docs/1696710760866831) |
| data | object | 返回数据 |
| list | object[] |  |
| clear\_id | number | 清理任务id |
| clear\_task\_params | object | 任务的参数 |
| material\_ids | number[] | 待清理的素材列表 |
| clear\_material\_types | string[] | 清理素材类型：  `INEFFICIENT_MATERIAL`低效素材；  `SIMILAR_MATERIAL` 同质化挤压严重素材；  `SIMILAR_QUEUE_MATERIAL` 同质化排队素材 |
| create\_time\_upper | string | 清理此日期之前创建的素材，格式为"yyyy-mm-dd"，不包含该日期 |
| start\_time | string | 账户下累积转化数和累积消耗数的数据统计开始时间，格式为"yyyy-mm-dd"，包含该日期 |
| end\_time | string | 账户下累积转化数和累积消耗数的数据统计结束时间，格式为"yyyy-mm-dd"，包含该日期 |
| material\_source | string | 清理的素材来源:  `AD`平台  `QIANCHUAN`千川 |
| convert | number | 账户下累积转化数，在start\_time和end\_time期间发生的累积转化数，清理小于该累积转化数的素材  当start\_time和end\_time传入时有效 |
| cost | float | 账户下累积消耗，在start\_time和end\_time期间发生的累积消耗，清理小于该累积消耗的素材  当start\_time和end\_time传入时有效 |
| create\_time | string | 任务创建时间，格式：`%Y-%m-%d %H:%M:%S` |
| task\_status | string | 任务状态:  `DONE` 已完成  `RUNNING` 运行中  `TIMEOUT`超时 |
| page\_info | object | 分页信息 |
| page | number | 页码 |
| page\_size | number | 页面大小 |
| total\_number | number | 总数 |
| total\_page | number | 总页数 |
