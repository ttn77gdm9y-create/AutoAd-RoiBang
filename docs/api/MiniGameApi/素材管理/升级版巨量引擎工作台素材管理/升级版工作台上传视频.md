# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `multipart/form-data` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 账户ID |
| account\_type | string | 账户类型，可选值:    * `EBP` 升级版（默认值） |
| upload\_type | string | 视频上传方式，可选值:    * `UPLOAD_BY_FILE` 文件上传（默认值） * `UPLOAD_BY_URL` URL链接上传 |
| video\_signature  条件必填 | string | 视频的md5值(用于服务端校验) ，当upload\_type=`UPLOAD_BY_FILE` 时有效且必填 |
| video\_file  条件必填 | file | 视频文件，当upload\_type=`UPLOAD_BY_FILE`时有效且必填      * 视频格式要求：视频码率>516kbps，大小≤500M，1280\*720<分辨率<2560\*1440，4s<时长<300s，允许格式：mp4、mpeg、3gp、avi |
| file\_name | string | 素材的文件名，可自定义素材名，不传择默认取文件名，最长255个字符  * 同一素材已上传，重新上传不会修改文件名称 |
| labels | string[] | 标签 |
| video\_url | string | 视频url地址  仅支持开发者购置连山云素材服务上传生成的tos链接上传，不支持其他三方链接地址 |
| is\_aigc | bool | 视频素材是否为AIGC生成 |

| Code | Message | 解决方案 |
| --- | --- | --- |
| 400172 | 解析文件失败，请检查传入的素材url/文件是否正确 | 排查建议：① 如您在上传视频，url上传方式仅支持连山url并且url可通过浏览器访问，格式如：https://xxxxxx.volces.com/xxxxx，接入指南详见：https://ad.oceanengine.com/cloud/doc/1756427622851659；② 如您在上传图片，url必须可通过浏览器访问，请自查url格式或采用文件上传解决问题 |
| 400173 | 视频签名校验失败，请检查视频MD5与传入的signature是否匹配 | 该报错一般是因为您上传的视频文件MD5与在接口传入的video\_signature（MD5）不一致，请检查源文件和MD5结果是否有出入或者使用在线MD5加密工具验证一下 |
| 400175 | URL上传视频仅支持连山云TOS存储，请先将短视频存储到连山云后再调用接口 | 该报错是因为您传入的视频url错误，系统找不到/无法访问这个URL。有2个排查方向：① url上传方式仅支持连山url并且url可通过浏览器访问；② 连山配置有误，TOS和VPC的区域务必选择华北（北京），否则无法内网上传。更多配置规则可参考：https://ad.oceanengine.com/cloud/doc/1756427622851659 |
