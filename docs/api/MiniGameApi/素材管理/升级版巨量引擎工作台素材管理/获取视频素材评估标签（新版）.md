**本接口是「**[**获取素材标签列表**](https://open.oceanengine.com/labels/34/docs/1761499216182279)**」、「**[**获取素材标签信息**](https://open.oceanengine.com/labels/34/docs/1763768835703812)**」接口的升级版，支持查询账户下视频库的素材评估标签。新接口在支持原接口能力的基础上，****扩展了以下****新能力：**

1. **account\_id支持4类平台账户：**巨量营销/巨量千川/工作台（组织）/方舟，即可查询4类账户下的素材评估标签。如果您管理账户量级大、查询素材量级多，可使用本接口，by工作台/方舟账户拉取账户下素材的评估标签

1. 工作台账户维度：可获取查询「资产」-「视频库」下所有视频素材的评估标签
2. 方舟账户维度：可获取方舟代理公司下的视频素材评估标签

2. **支持查询素材存在搬运风险标签：**

1. 搬运授权保护的维度为投放账户，请使用巨量营销/巨量千川账户查询该标签。
2. 接口目前返回工作台/方舟账户维度下「存在搬运风险」标签，仅代表一个素材在工作台/方舟下的某个投放账户下存在搬运风险，暂不支持查询关联账户信息。

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 各平台账户id，必须同时选择account\_type类型 |
| account\_type  必填 | string | 账户类型， 可选值:   * `BP` 巨量引擎工作台 * `AGENT` 巨量方舟 * `AD` 巨量营销 * `QIANCHUAN` 巨量千川 * `LOCAL` 巨量本地推 |
| filtering | object | 过滤条件  不同条件之间为「且」的关系，只有同时满足传入的多个条件，才会返回信息 |
| material\_ids | number[] | 按素材ID过滤，范围为1-1000 |
| material\_properties | string[] | 素材标签过滤项，如果不传，则默认返回客户ID下所有素材。   * 传入多个允许值，该参数多个值之间为「或」的关系，只要素材存在某一种类型的标签，都会在应答参数中返回。   允许值：   * `AIGC` AIGC素材 * `FIRST_PUBLISH_MATERIAL` 首发素材 * `AD_HIGH_QUALITY_MATERIAL`  AD优质素材 * `ECP_HIGH_QUALITY_MATERIAL` 千川优质素材 * `LOCAL_HIGH_QUALITY_MATERIAL`  本地推优质素材 * `AD_LOW_QUALITY_MATERIAL` AD低质素材 * `ECP_LOW_QUALITY_MATERIAL` 千川低质素材 * `LOCAL_LOW_QUALITY_MATERIAL`  本地推优质素材 * `INEFFICIENT_MATERIAL` 低效素材 * `SIMILAR_MATERIAL` 新同质化素材 * `SIMILAR_QUEUE_MATERIAL` 同质化排队素材 * `CARRY_MATERIAL`存在搬运打压风险 |
| start\_time | string | 起始日期，表示按照素材上传到账户下的时间过滤，格式为yyyy-mm-dd HH:MM:SS，最早允许传入时间：2022-01-01 00:00:00 （时间是账号和素材绑定的时间，删除重绑时间会更新） |
| end\_time | string | 结束日期，表示过滤出一段时间内上传的素材，格式为yyyy-mm-dd HH:MM:SS，如果传入起始日期，未传此参数，则默认为当前时间 |
| attributes\_modify\_time | string | 「存在搬运打压风险」属性最后一次更新时间，格式为yyyy-mm-dd ，筛选传入代表筛选出当天「存在搬运打压风险」发生过变化的素材信息 |
| return\_lowquality\_suggestions | bool | 应答参数是否返回低质原因，不传或传入false时，应答参数不返回低质原因  当素材为低质素材时，可查询素材低质原因，允许值：   返回：true  不返回：false |
| page\_size  必填 | number | 页面数据量，默认值: 100，page\*page\_size 最大1000 |
| page  必填 | number | 页码，默认值: 1，page\*page\_size 最大1000 |
