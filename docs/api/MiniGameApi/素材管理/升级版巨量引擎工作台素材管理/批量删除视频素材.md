通过此接口，用户可以对素材视频进行批量删除。

当素材删除失败时，会展示在video\_id列表，不在此列表内的素材表示删除成功！

### 请求方法

POST

### 请求Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Content-Type 必填 | string | 请求消息类型，允许值：`application/json` |
| Access-Token 必填 | string | 授权access-token，获取方法见接口文档[【获取Access-Token】](https://open.oceanengine.com/labels/7/docs/1696710505596940) |

### 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id 必填 | number | 素材归属的客户 |
| video\_ids | string[] | 待删除的video\_id列表，长度范围：1 ~ 100 |
| material\_ids | number[] | 待删除的material\_id列表，长度范围：1 ~ 100  注意：video\_ids和material\_ids至少填一个 |

# 业务错误码

仅披露当前接口高频的参数校验报错，更多常见报错详见[「返回码」](https://open.oceanengine.com/labels/34/docs/1696710760866831)文档

| Code | Message | 解决方案 |
| --- | --- | --- |
| 400137 | 参数有误，请检查必填参数是否已填/图片id是否重复 | 该报错可能原因较多，如您在上传图文时碰到此报错，可检查入参中images结构体下是否有重复的image\_id，如有则去掉重复值重新请求。其余场景报错，建议您隔一段时间重试，如稳定报错可前往开放平台官网寻求帮助 |
| 400171 | 视频权限查询失败 | 排查方向：① 请检查您传入的video\_ids是否正确，video\_id格式为string，通常为字母+数字的形式，如“：v02033g11111d03jhjnog65p1u6b6mr0”，视频每一次上传到平台都会产生新的video\_id。而material\_id是纯数字格式，一个视频signature只会对应一个material\_id；② 很可能是因为您上传视频后立马操作推送，视频此时还未完全上传成功，请等待2-3分钟后再重试 |
