本接口支持查询投放账户下自2024年4月26日起上传的音频素材，不支持查询版权音频相关信息

* 音频试听url仅限开发者账户与投放账户同主体时可获取，若非同主体会返回“素材所属主体与开发者主体不一致无法获取URL”
* 第三方获取敏感物料信息可在授权时申请投放账户授权敏感物料权限，可参考常见问题【[敏感物料授权](https://ad.oceanengine.com/athena/faq/index.html?plat_id=7&id=1675539226863629)】

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 投放账户ID |
| filtering | object | 过滤条件 |
| audio\_ids | string[] | 按音频id过滤，list长度 1-100 注意audio\_ids，material\_ids，audio\_signatures三者只能选一个过滤，同时传入会报错 |
| material\_ids | number[] | 按音频素材id（全局唯一）过滤，list长度1-100 注意audio\_ids，material\_ids，audio\_signatures三者只能选一个过滤，同时传入会报错 |
| signatures | string[] | 按音频md5过滤，list长度1-100 注意audio\_ids，material\_ids，audio\_signatures三者只能选一个过滤，同时传入会报错 |
| sources | string[] | 音频素材来源 枚举值大小写敏感，请严格按照定义的名称传参  `AD_SITE`AD后台本地上传  `OPEN_API` 开放平台上传  `TTS_TEXT_TO_AUDIO`文本转音频 |
| start\_time | string | 根据音频上传时间过滤，与end\_time搭配使用，格式：yyyy-mm-dd hh:mm:ss |
| end\_time | string | 根据音频上传时间过滤，与start\_time搭配使用，格式：yyyy-mm-dd hh:mm:ss |
| page | number | 页码 |
| page\_size | number | 页面大小 |
