EBP场景下，对组织维度的素材进行共享

1. 仅支持将组织维度的全部素材共享给另一个组织，不支持单素材共享，不支持共享给账户、主体
2. 共享的操作人默认=共享的素材范围，仅支持共享某组织节点下【仅直属】素材

# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 账户ID |
| account\_type | string | 账户类型，可选值:    * `EBP` 升级版工作台（默认值） |
| target\_ebps  必填 | object[] | 被共享的EBP组织，数量限制[1,20] |
| target\_ebp\_id  必填 | number | 被共享的EBP组织ID |
| target\_ebp\_range  必填 | string | 被共享的组织范围，可选值:    * `ALL` 全部 * `SELF` 仅直属 |
| material\_type | string | 素材类型，可选值:    * `VIDEO` 视频（默认值） |
