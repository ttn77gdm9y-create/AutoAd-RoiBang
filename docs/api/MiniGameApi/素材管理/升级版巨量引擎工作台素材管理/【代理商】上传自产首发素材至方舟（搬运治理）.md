代理商可以通过此接口将「首发素材」上传视频素材至巨量方舟，上传后「首发素材」即可自动完成保护（前置需要先完成整体保护授权，参考详细文档介绍[「搬运治理-首发保护」说明手册（可对外）](https://bytedance.larkoffice.com/docx/Fpn4dn4ldoAHrmxrCEfcpWO1n8f)）。**保护后系统将根据代理授权范围识别搬运素材生效打压，避免其他方抢夺代理的流量。**

* **注意1：**建议代理商务必将自己制作的「首发素材」先通过本接口上传到方舟平台（素材才可能按照代理授权生效，否则可能会被客户先做授权保护），避免素材被其他方抢先保护。
* **注意2：**非首发素材，即使进行上传也不会生效授权保护（[点此查看「首发素材」相关说明](https://bytedance.larkoffice.com/docx/IYTId7xsEo8p3ax3YkHcTHdxnNb)）
* **注意3：**调用接口上传的素材可在“方舟-优化-新版素材管理-公司素材库”查看
* **注意4：**本接口支持巨量营销代理商、巨量千川代理商完成授权后，调用接口上传视频素材至巨量方舟

# 请求参数

| agent\_id  必填 | number | 代理商id |

| video\_file | file | 视频文件数据，upload\_type为`UPLOAD_BY_FILE`必填   * 文件支持格式：mp4,mpeg,3gp,avi * 文件大小要求：＜1000M * 文件分辨率要求：>=1280\*720 |
| video\_url | string | 视频URL地址，upload\_type为`UPLOAD_BY_URL`必传 只支持连山tos地址，接入流程详见：<https://ad.oceanengine.com/cloud/doc/1756427622851659> |

| file\_name  必填 | string | 视频上传名称 |
| is\_aigc | bool | 是否为AIGC生成，允许值：   * false （默认值） * true |
| is\_need\_auth  必填 | bool | 标注是否允许生效代理商公司的首发保护授权范围  （允许授权的前提是素材是代理商自产且与客户达成了一致）   * true (默认值） * false (仅用于素材前测时请输入false) |
