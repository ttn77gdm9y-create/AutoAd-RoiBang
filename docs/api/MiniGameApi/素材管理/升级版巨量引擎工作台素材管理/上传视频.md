POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `multipart/form-data` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 客户ID |
| upload\_type | string | 视频/音频上传方式，允许值：   * `UPLOAD_BY_FILE` 文件上传 * `UPLOAD_BY_URL` 网址上传   默认值: `UPLOAD_BY_FILE` |
| video\_signature | string | 视频的md5值(用于服务端校验)   * upload\_type =`UPLOAD_BY_FILE`有效且必填 |
| video\_file  条件必填 | file | 视频文件，允许格式：mp4、mpeg、3gp、avi、m4v，文件大小≤500M   * upload\_type为`UPLOAD_BY_FILE`有效且必填 |
| filename  条件必填 | string | upload\_type = `UPLOAD_BY_URL`有效且必填  素材的文件名，可自定义素材名，不传择默认取文件名，最长255个字符 注：若同一素材已进行上传，重新上传不会改名。 |
| labels | string[] | 标签 |
| video\_url | string | 视频 url地址，如<http://xxx.xxx>，upload\_type为`UPLOAD_BY_URL`必填   * 仅支持开发者购置连山云素材服务上传生成的tos链接上传，不支持其他三方链接地址，具体见[接入指南](https://ad.oceanengine.com/cloud/doc/1756427622851659) * 建议：对于连山url链接上传视频，请及时切换至[异步上传接口](https://open.oceanengine.com/labels/7/docs/1801533703648324) |
| is\_aigc | bool | 视频素材是否为AIGC生成 |
| is\_guide\_video | bool | 上传视频场景是否是引导视频（此功能仅游戏行业白名单客户可用，如需使用请联系运营） |
