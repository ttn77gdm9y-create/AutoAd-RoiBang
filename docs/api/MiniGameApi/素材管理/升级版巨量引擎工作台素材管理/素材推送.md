本接口支持推送投放账户下已有的视频素材

* 不支持推送组织共享的视频素材
* 当素材在被推送账户下已存在，素材文件名、来源不会变化，仅更新素材的上传时间
* 一次请求推送限制需满足：推送视频数＜=50、推送账户数\*推送视频数＜=1000

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 素材归属客户 |
| target\_advertiser\_ids  必填 | number[] | 待推送的客户，数量限制：<=50 |
| video\_ids | string[] | 视频ID，数量限制：   * 视频个数<=50 注意：跟image\_ids、carousel\_ids必须三选一、旧版巨量引擎工作台共享视频不可推送 * 推送账户数\*素材数需<=1000 |
| image\_ids | string[] | 图片ID，数量限制：   * 视频个数<=50 注意：跟video\_ids、carousel\_ids必须三选一 * 推送账户数\*素材数需<=1000 |
| carousel\_ids | number[] | 图集ID，数量限制：   * 视频个数<=50 注意：跟image\_ids、video\_ids必须三选一 * 推送账户数\*素材数需<=1000 |

# 业务错误码

仅披露当前接口高频的参数校验报错，更多常见报错详见[「返回码」](https://open.oceanengine.com/labels/34/docs/1696710760866831)文档

| Code | Message | 解决方案 |
| --- | --- | --- |
| 400170 | 部分视频无权限或不存在 | 排查方向：① 请检查您传入的video\_ids是否正确，video\_id格式为string，通常为字母+数字的形式，如“：v02033g11111d03jhjnog65p1u6b6mr0”，视频每一次上传到平台都会产生新的video\_id。而material\_id是纯数字格式，一个视频signature只会对应一个material\_id；② 很可能是因为您上传视频后立马操作推送，视频此时还未完全上传成功，请等待2-3分钟后再重试 |
| 400174 | 部分图片无权限或不存在 | 该报错很可能是因为您上传图片后立马操作推送，图片此时还未完全上传成功，请等待2-3分钟后再重试 |
| 400176 | 目标广告主${1}与原广告主不属于同一主体 | 这里验证的主体是广告投放账户和被推送广告主账户之间的主体是否一致。查询广告主主体，您可参考：https://open.oceanengine.com/labels/7/docs/1741478619724813? |
