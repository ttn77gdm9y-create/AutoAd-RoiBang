# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 账户ID |
| account\_type  必填 | string | 账户类型，允许值：   * `EBP` 升级版巨量引擎工作台 |
| asset\_management\_scope | string | 查询资产范围，允许值：   * `DIRECT` 直属，仅查询入参组织创建的资产 * `TRAVERSE` 全部，查询入参组织及下属组织创建的所有资产 |
| filtering | object | 过滤条件 |
| name | string | 小程序名称或备注的模糊匹配 |
| search\_key | string | 搜索条件 |
| asset\_ownership | string | 资产归属关系类型，允许值：   * `ALL` 全部 * `CREATE` 管理的 * `SHARE` 被共享的 |
| audit\_status | string | 审核状态，允许值：   * `AUDIT_ACCEPTED` 审核成功 * `AUDITING` 审核中 * `AUDIT_REJECTED` 审核失败 * `ALL` 查全部 |
| username | string | 原始ID |
| page | number | 页数，默认值为`1` |
| page\_size | number | 页面大小，默认值为`10`，最大值`100` |
