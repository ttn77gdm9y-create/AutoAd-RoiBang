# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id  必填 | number | 客户ID |
| name  必填 | string | 小程序名称，须与小程序实际名称保持一致，最大长度不超过50 |
| user\_name  必填 | string | 小程序原始ID，获取方式：小程序后台>设置>基本设置>账号信息>原始ID，例如“gh\_”，最大长度不超过20 |
| path | string | 小程序路径参数，如有跳转指定页面或自定义参数监测营销效果数据诉求，需填写。获取方式：登录关联的公众号后台>素材管理>新建图文素材>小程序>选择小程序>获取更多路径 |
| remark\_message | string | 资产备注信息，最大长度不超过15 |
| icon\_image\_url | string | 小程序icon图片的url，尺寸60\*60px,大小不超2MB  图片格式要求jpeg、png或gif |
| header\_image\_url | string | 顶部头图的url，大小不超过5MB的图片，推荐尺寸2:1  图片格式要求jpeg、png或gif |
| labels | string[] | 小程序标签，每个标签长度不超过6，最多支持6个标签 |
| guide\_text | string | 引导文案，最大长度不超过14 |
| images\_vertical\_url | string[] | 小程序竖图URL地址   * 小程序竖图的url地址，要求尺寸必须为3:5，否则报错。 * 仅支持竖图和横图择其一类型上传，若同时上传两种类型的图片则报错 * 小程序横图或竖图上传最少3张，最多8张，大小不超过5MB * 图片格式要求jpeg、png或gif |
| images\_horizontal\_url | string[] | 小程序横图URL地址   * 小程序横图的url地址，要求尺寸必须为3:5，否则报错。 * 仅支持竖图和横图择其一类型上传，若同时上传两种类型的图片则报错 * 小程序横图或竖图上传最少3张，最多8张，大小不超过5MB * 图片格式要求jpeg、png或gif |
| introduction | string | 小程序简介，最大长度不超过50 |
| tag\_info  必填 | string | 细分类型  填写细分类型的末级分类ID category\_id，分类及ID详见[【应用管理标签及类目】](https://open.oceanengine.com/labels/7/docs/1812331394774028?origin=left_nav) |
| payment\_form  条件必填 | string | 付费形式   * 支持类目：工具、社交，仅该两个类目下参数必填  可选值:    * `BOTH_OPTIONS_AVAILABLE` 以上两者兼有 * `CONTENT_OR_SERVICES` 付费购买内容或服务 * `UNLOCK_FULL_FEATURES` 付费解锁完整功能 |
| membership\_type  条件必填 | string | 会员类型   * 支持类目：工具、社交，仅该两个类目下参数必填  可选值:    * `ANNUAL` 年度 * `LIFETIME` 终身 * `MONTHLY` 月度 * `NONE` 无 * `WEEKLY_DAILY` 周/天 |
| revenue\_model  条件必填 | string | 变现模式   * 支持类目：工具、社交、游戏道具售卖，仅该类目下参数必填  可选值:    * `IAA` 营销 * `IAAP` 混合 * `IAP` 付费 |
| has\_online\_earning  条件必填 | bool | 是否包含网赚内容   * 支持类目：工具、社交，仅该类目下参数必填 * 当变现模式为付费/混合时必填 |
| max\_recharge\_tier  条件必填 | string | 最高充值档位（元）   * 支持类目：工具、社交，仅该类目下参数必填 * 当变现模式为付费/混合时必填  可选值:    * `ABOVE_200` 200以上 * `FROM_100_TO_200` 100-200 * `FROM_FIFTY_TO_HUNDRED` 50-100 * `FROM_ONE_TO_FIFTY` 1-50 |
| min\_recharge\_tier  条件必填 | string | * 最低充值档位（元） * 支持类目：工具、社交，仅该类目下参数必填 * 当变现模式为付费/混合时必填  可选值:    * `FROM_100_TO_200` 100-200 * `FROM_FIFTY_TO_HUNDRED` 50-100 * `FROM_ONE_TO_FIFTY` 1-50 |
| recommended\_recharge\_tier | string | * 推荐充值档位（元） * 支持类目：工具、社交 * 当变现模式为付费/混合时选填  可选值:    * `ABOVE_200` 200以上 * `FROM_100_TO_200` 100-200 * `FROM_FIFTY_TO_HUNDRED` 50-100 * `FROM_ONE_TO_FIFTY` 1-50 |
| prop\_name | string | 道具名称 |
| min\_payment\_tier\_range  条件必填 | string | 最低付费档位区间（元）   * 支持类目：游戏道具售卖，必填 * 当变现模式为付费/混合时必填  可选值:    * `SIX_TEN` 6~10 * `TEN_TWENTY` 10~20 * `TWENTY_FIFTY` 20~50 * `ZERO_FIVE` 0~5 |
| mid\_payment\_tier\_range  条件必填 | string | 中间付费档位区间（元）   * 支持类目：游戏道具售卖 * 当变现模式为付费/混合时必填     可选值:   * `ABOVE_500` 500以上 * `BELOW_100` 100以下 * `FROM_100_TO_500` 100~500 |
| max\_payment\_tier\_range  条件必填 | string | 最高付费档位区间（元）   * 支持类目：游戏道具售卖必填 * 当变现模式为付费/混合时必填     可选值:   * `ABOVE_1000` 1000以上 * `BELOW_500` 500以下 * `FROM_500_TO_1000` 500-1000 |
| has\_discount  条件必填 | bool | 是否有折扣   * 支持类目：游戏道具售卖必填 * 当变现模式为付费/混合时必填 |
| discount\_rate | number | 折扣比例   * 支持类目：游戏道具售卖 * 当变现模式为付费/混合，且是否有折扣=是 时选填 |
