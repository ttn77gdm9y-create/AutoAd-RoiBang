# Header

| 字段 | 类型 | 描述 |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 账户ID |
| account\_type  必填 | string | 账户类型，可选值:   * `EBP` 升级版巨量引擎工作台 |
| basic\_package\_id  必填 | string | 应用包id |
| app\_name  必填 | string | 应用名称 |
| permissions\_description  必填 | string | 隐私权限说明 |
| update\_description  必填 | string | 版本更新说明 |
| recommend  必填 | string | 推荐语 |
| app\_description  必填 | string | 应用简介 |
| payment\_type  必填 | string | 付费类型 可选值:    * `FREE` 免费下载，且不包含付费内容 * `PRODUCT` 免费下载，但应用内包含付费内容，如道具等虚拟物品 * `TRIAL_AND_LIMIT_FUNCTIONS` 付费使用完整功能，且应用内包含付费内容，如道具等虚拟物品 * `TRIAL_AND_PURCHASE` 付费使用完整功能，但应用内不包含任何付费内容 |
| developer\_name  必填 | string | 开发者名称 |
| auto\_publish  必填 | bool | 是否自动发布 |
| theme\_tag\_id  条件必填 | string | 游戏应用题材标签 |
| files  必填 | object[] | 文件内容  必须包含一个apk；可选：五个图片、一个视频 |
| upload\_id  必填 | number | 文件上传id |
| file\_type  必填 | string | 文件类型 可选值:    * `APK` APK包文件 * `IMAGE` 图片文件 * `VIDEO` 视频文件 |
| file\_tag | string | 文件标识 可选值:    * `AGE_REMINDER` 适龄提醒 * `ANTI_ADDICTION_TIPS` 防沉迷提示 * `DEFAULT` 默认 * `MATERIAL_SCREENSHOT` 素材截图 * `REAL_NAME_VERIFIED` 实名注册 |
| file\_option  必填 | string | 文件选项 可选值:    * `USE_LAST_IMAGE_VIDEO` 使用上一次的图片、视频 * `USE_NEW` 使用新图片、视频 |
| category\_id  必填 | number | 应用类型  填写末级分类id，分类及id详见[【应用管理标签及类目】](https://open.oceanengine.com/labels/7/docs/1812331394774028?origin=left_nav) |
| art\_style  条件必填 | string | 画风分类  应用-游戏类目下该参数必填  填写题材标签的末级分类ID category\_id，分类及ID详见[【应用管理标签及类目】](https://open.oceanengine.com/labels/7/docs/1812331394774028?origin=left_nav) |
| network\_environment  条件必填 | string[] | 网络环境  应用-游戏类目下该参数必填,最多支持传入3个  填写网络环境的末级分类ID category\_id，分类及ID详见[【应用管理标签及类目】](https://open.oceanengine.com/labels/7/docs/1812331394774028?origin=left_nav) |
| feature\_tags  条件必填 | string[] | 特色标签  应用-游戏类目下该参数必填,最多支持传入3个  填写网络环境的末级分类ID category\_id，分类及ID详见[【应用管理标签及类目】](https://open.oceanengine.com/labels/7/docs/1812331394774028?origin=left_nav) |
| game\_box\_name | string | 盒子内游戏名称,  自定义填写,仅题材标签=游戏盒子时需填写 |
| game\_ip\_type | string[] | 可选值:    * `Animation`动漫类IP * `Artistic`文化艺术类IP * `Film`影视类IP * `Literary`文学类IP * `None`无IP * `Others`其他 |
| game\_ip\_tag | string | 细分IP，自定义填写，举例：如三国、西游等 |
| spokesperson | string | 代言人名字，自定义填写 |
| revenue\_model  必填 | string | 变现模式，可选值:    * `IAA` 营销 * `IAAP` 混合 * `IAP` 付费 |
| has\_online\_earning | bool | 是否包含网赚内容 |
| min\_payment\_tier\_range  条件必填 | string | 最低付费档位区间（元）可选值:    * `SIX_TEN` 6~10 * `TEN_TWENTY` 10~20 * `TWENTY_FIFTY` 20~50 * `ZERO_FIVE` 0~5 |
| mid\_payment\_tier\_range  条件必填 | string | 中间付费档位区间（元）可选值:    * `ABOVE_500` 500以上 * `BELOW_100` 100以下 * `FROM_100_TO_500` 100~500 |
| max\_payment\_tier\_range  条件必填 | string | 最高付费档位区间（元）可选值:   * `ABOVE_1000` 1000以上 * `BELOW_500` 500以下 * `FROM_500_TO_1000` 500-1000 |
| max\_recharge\_tier  条件必填 | string | 最高充值档位（元）可选值:   * `ABOVE_200` 200以上 * `FROM_100_TO_200` 100-200 * `FROM_FIFTY_TO_HUNDRED` 50-100 * `FROM_ONE_TO_FIFTY` 1-50 |
| min\_recharge\_tier  条件必填 | string | 最低充值档位（元）可选值:   * `FROM_100_TO_200` 100-200 * `FROM_FIFTY_TO_HUNDRED` 50-100 * `FROM_ONE_TO_FIFTY` 1-50 |
| recommended\_recharge\_tier | string | 推荐充值档位（元），可选值:    * `ABOVE_200` 200以上 * `FROM_100_TO_200` 100-200 * `FROM_FIFTY_TO_HUNDRED` 50-100 * `FROM_ONE_TO_FIFTY` 1-50 |
| schedule\_cards  条件必填 | number[] | 是否含周卡/月卡/季卡等  应用-游戏类目下参数必填  仅对变现模式=付费、混合支持传入  可选值:   * `Annual` 年卡 * `Lifetime` 终身卡 * `Monthly` 月卡 * `None` 无 * `Quarterly` 季卡 * `Weekly` 周卡 |
| has\_discount  条件必填 | bool | 是否有折扣  应用-游戏类目下参数必填 |
| discount\_rate  条件必填 | number | 折扣比例  应用-游戏类目下参数必填  题材标签=游戏盒子，且变现模式=付费、混合，是否有折扣=是 支持传入  填写实际折扣力度，仅支持整数形式，如游戏盒子付费9折可填写 90 |
| membership\_type  条件必填 | string | 会员类型，应用-软件-工具&社交类目下参数必填，可选值:    * `ANNUAL` 年度 * `LIFETIME` 终身 * `MONTHLY` 月度 * `NONE` 无 * `WEEKLY_DAILY` 周/天 |
