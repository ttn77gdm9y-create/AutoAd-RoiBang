# 请求方法

GET

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 账户ID |
| account\_type  必填 | string | 账户类型，允许值：   * `EBP` 升级版巨量引擎工作台 |
| package\_id  必填 | string | 应用包ID |
| filtering | object | 过滤器 |
| status | string | 筛选应用状态，可选值：   * `All` 全部 * `Prepared` 未更新 * `Creating` 创建中 * `Updating` 更新中 * `Published` 已发布 * `CreateFail` 创建失败 * `UpdateFail` 更新失败 * `Offline` 已下架 |
| channel\_id\_list | string[] | 渠道号，可通过渠道号筛选应用分包，单次支持传入渠道号个数<=50 |
| page | number | 页码，默认值为`1` |
| page\_size | number | 页面大小，默认值为`10`，范围为[1,100] |
| update\_time | object | 时间范围 |
| start\_time | string | 开始时间，示例:`2024-07-01 00:00:00` |
| end\_time | string | 结束时间，示例:`2024-07-01 23:59:59` |

    """

def get(json_str):
    # type: (str) -> dict
    """

    args = json.loads(json_str)

    url = build_url(PATH, query_string)
