# 请求方法

POST

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 账户ID |
| account\_type  必填 | string | 账户类型，允许值：   * `EBP` 升级版巨量引擎工作台 |
| package\_id  必填 | string | 母包ID |
| mode  必填 | string | 分包模式，可选值：   * `AUTO` 自动 * `CUSTOMIZE` 自定义 * `MANUAL`手动 |
| channel\_count | number | 自动生成模式下要指定数量 |
| channel\_info\_list | object[] | 自定义模式下必须传入渠道号信息 |
| channel\_id  必填 | string | 渠道号，渠道号ID支持英文，数字，下划线和连字符-，不超过50个字符，超出部分会被截断  示例：oceanengine\_ads\_sample-12 |
| remark | string | 备注，渠道包备注信息，至多20个字符，超出部分会被截断处理 |
| download\_url | string | 渠道包（子包）的下载地址，当前不支持修改 |
| cdn\_path | string |  |
| md5 | string | 渠道包（子包）文件md5 |
