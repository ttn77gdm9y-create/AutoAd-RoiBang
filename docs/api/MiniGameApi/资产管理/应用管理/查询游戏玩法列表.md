# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id  必填 | number | 账户id，需传入有权限使用资产的账户id（创建资产的账户或bp下的账户，或申请过资产共享） |
| account\_type  必填 | string | 账户类型，可选值:   * `AD`：投放账户 |
| asset\_id  必填 | string | 资产id，可通过应用、小游戏列表获取接口获取资产id  安卓应用：应用列表接口出参package\_id  抖音/微信小游戏：列表接口出参instance\_id |
| asset\_type  必填 | string | 上述资产id所属资产类型，可选值:    * `APP` 安卓应用 * `BYTE_GAME` 字节小游戏 * `WECHAT_GAME` 微信小游戏 |
| filter\_play\_names | string[] | 玩法名称筛选，支持模糊搜索 |
| page\_info | object | 分页信息 |
| page | number | 页码，默认值为`1` |
| page\_size | number | 页面大小，默认值为`10`，最大值`100` |
