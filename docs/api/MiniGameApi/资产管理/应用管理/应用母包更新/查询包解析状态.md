查询包解析状态，用于创建包含游戏礼包码的营销计划时，[【提交解析应用包任务】](https://ad.oceanengine.com/openapi/doc/index.html?id=1696710744089612)后，查询应用包的解析状态。 当返回参数`package_status`包解析状态为`“SUCCESS”`时表示包解析已经完成。此时，您可以提交创建营销计划。

如果在没有解析完成时提交营销计划可能导致游戏礼包码的原生转化卡信息展示不全。
