> 创建应用分包，支持所有账户体系下创建应用分包

母包package创建成功后，可以通过当前接口创建分包，支持AD、巨量引擎工作台-旧版及巨量引擎工作台-升级版客户。

目前API开放平台不支持母包package的创建，创建母包需要前往 投放平台-资产-移动应用

应用类型:  自研投放应用-客户/代理商/独立三方站点/群峰上架服务、提供第三方服务-客户/代理商/独立三方站点/群峰上架服务

接入能力范围:  巨量 PC

# 请求方法

**POST**

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token必填 | string | 授权access\_token，可以通过[【获取Access token】](https://open.oceanengine.com/labels/7/docs/1696710505596940)接口获取 |
| Content-Type必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| account\_id | number | 账户id，account\_type类型对应账户ID（近期升级到巨量引擎工作台-升级版的客户请传入应用包所属旧版巨量引擎工作台/子旧版巨量引擎工作台ID，账户类型传入旧版巨量引擎工作台） |
| account\_type | string | 账户类型 允许值：   * `旧版巨量引擎工作台` 巨量引擎工作台-升级版/旧版 * `AD` 客户账号 * `STAR` 星图 |
| package\_id | string | 应用包ID，可通过「查询应用信息」接口查询获取 |
| mode | string | 分包模式 允许值：   * `Auto` 自动生成渠道号 * `Manual` 自定义渠道号信息 |
| channel\_count条件必填 | number | 自动创建分包数量，数量限制：`1`~`100`分包模式mode为`Auto`时可用且必填 |
| channel\_list条件必填 | object[] | 自定义渠道号信息，数量限制：`1`~`100`分包模式mode为`Manual`时可用且必填 |
| channel\_id必填 | string | 渠道号，渠道号ID支持英文，数字，下划线和连字符-，不超过50个字符，超出部分会被截断 示例：oceanengine\_ads\_sample-12 |
| remark | string | 备注，渠道包备注信息，至多20个字符，超出部分会被截断处理 |
