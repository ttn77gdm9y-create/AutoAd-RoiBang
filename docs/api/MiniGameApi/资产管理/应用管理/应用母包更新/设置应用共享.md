该接口为增量共享

# 请求方法

**POST**

# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token必填 | string | 授权access\_token，可以通过[【获取Access token】](https://open.oceanengine.com/labels/7/docs/1696710505596940)接口获取 |
| Content-Type必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| organization\_id | number | 巨量引擎工作台id |
| package\_id | string | 应用包ID， 可通过[「查询安卓应用信息」](https://open.oceanengine.com/labels/7/docs/1696710742760448)接口查询获取package\_id |
| share\_mode | string | 共享类型 允许值：  `PART` 指定账户共享  `ALL` 巨量引擎工作台内某类型所有账户共享  `COMPANY` 公司主体内某类型所有账户共享 |
| all\_accounts条件必填 | object[] | 共享账号类别，一次最多操作`10`个 当share\_mode 为`ALL`时可用且必填 |
| account\_type必填 | string | 业务线 枚举值：`AD` 营销、`STAR` 星图 |
| account\_infos条件必填 | object[] | 共享账号信息，一次最多操作10个 当share\_mode为 `PART`时可用且必填 |
| account\_type必填 | string | 业务线 枚举值：`AD` 营销、`STAR` 星图、`BP` 巨量引擎工作台 |
| account\_id必填 | number | 账号id |
| all\_account\_by\_company条件必填 | object[] | 公司主体信息，一次最多操作1个 当share\_mode为 `COMPANY`时可用且必填 |
| account\_type必填 | string | 业务线 枚举值：`AD` 营销、`STAR` 星图 |
| company\_id必填 | number[] | 公司主体id, 一次最多操作10个 |
