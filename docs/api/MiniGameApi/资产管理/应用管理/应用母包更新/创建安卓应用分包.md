通过客户id和应用包id，为应用包创建对应的分包信息。

> 目前开放平台不支持母包package的创建，创建母包需要前往 [投放平台-资产-移动应用](https://ad.oceanengine.com/app_package/applist?aadvid=4645318181) ；  
> 母包package创建成功后，可以通过当前接口创建分包。

单个package目前支持分包上限3000个；

单次创建分包数量上限是100。

### 请求方法

POST

### 请求Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Content-Type必填 | string | 请求消息类型，允许值：`application/json` |
| Access-Token必填 | string | 授权access-token，获取方法见接口文档[【获取Access-Token】](https://open.oceanengine.com/labels/7/docs/1696710505596940) |

### 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| advertiser\_id必填 | number | 客户ID |
| package\_id必填 | string | 应用包ID，获取方法见接口文档[【查询应用信息】](https://ad.oceanengine.com/openapi/doc/index.html?id=1696710742760448) |
| mode必填 | string | 分包模式，`Auto`自动生成渠道号`Manual`自定义渠道号信息 |
| channel\_count | number | 创建数量，（mode=`Auto`时需指定）单次分包取值范围`1~100` |
| channel\_list | object[] | 自定义渠道号信息，（mode=`Manual`时需指定），一次调用，list的size取值范围`1~100` |
| channel\_id | string | 渠道号，渠道号ID支持英文，数字，下划线和连字符-，不超过50个字符，超出部分会被截断，示例：`oceanengine_ads_sample-12` |
| remark | string | 备注，渠道包备注信息，至多20个字符，超出部分会被截断处理 |
