使用场景：创建的字节小程序将归属于升级版巨量引擎工作台，创建小程序的组织及下级组织绑定的账户默认可以使用小程序投放

**请注意**：两种方式仅生效一种。当以上三个参数均有值时，将按照schema\_info.link生效逻辑。

* **方式一**：录入链接信息，链接中可包含自定义的参数，但需确保链接能够成功调起小程序。以此方式创建资产，仅生效参数 schema\_info.link 。若同时传入参数 schema\_info.start\_page 与 schema\_info.start\_param ，后二者参数无效，以 schema\_info.link 中解析出的内容为准。
* **方式二**：（推荐）录入链接信息：确保参数 schema\_info.link 为空值，同时参数 schema\_info.start\_page 与 schema\_info.start\_param 填写应符合提示规范。
