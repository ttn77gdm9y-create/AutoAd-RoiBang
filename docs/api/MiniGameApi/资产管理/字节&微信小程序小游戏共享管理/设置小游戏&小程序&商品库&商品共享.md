# Header

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| Access-Token  必填 | string | 授权access\_token，可以通过【[获取Access token](https://open.oceanengine.com/labels/7/docs/1696710505596940)】接口获取 |
| Content-Type  必填 | string | 请求消息类型 允许值: `application/json` |

# 请求参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| organization\_id  必填 | number | 旧版巨量引擎工作台组织ID |
| instance\_id  必填 | number | 资产ID |
| asset\_type  必填 | string | 资产类型 可选值:   * `APPLETS` 微信小程序 * `WECHAT_GAME` 微信小游戏 * `BYTED_APPLETS` 字节小程序 * `BYTED_GAME` 字节小游戏 * `PRODUCT` 升级版商品 * `DPA` 通用版商品库 |
| share\_mode  必填 | string | 共享类型 可选值:   * `BP_ALL_ACCOUNTS` 旧版巨量引擎工作台内所有账户共享 * `COMPANY_ALL_ACCOUNTS` 公司主体内所有账户共享 * `PART` 指定账户共享 |
| all\_accounts\_by\_bp  条件必填 | string[] | 共享账号类别，当share\_mode 为`BP_ALL_ACCOUNTS`时有效且必填，一次最多操作1个，枚举值：`AD` 营销 |
| account\_infos  条件必填 | object[] | 共享账号信息，当share\_mode= `PART`时有效且必填，一次共享最多支持100个账号信息 |
| account\_type  条件必填 | string | 业务线，枚举值：`AD` 营销、`BP` 旧版巨量引擎工作台 |
| account\_id  条件必填 | number | 账户ID   * 共享到巨量引擎工作台组织时仅支持合作组织账号，需通过巨量引擎工作台>>设置>>合作组织管理>>添加合作组织进行管理； * 且仅创建在巨量引擎工作台组织下的微信小游戏资产支持共享到其他组织 |
| all\_accounts\_by\_company  条件必填 | object[] | 公司主体信息，一次最多操作1个 当share\_mode为 `COMPANY_ALL_ACCOUNTS`时有效且必填 |
| account\_type  条件必填 | string | 业务线 可选值:   * `AD` 营销 |
| company\_id  条件必填 | number | 公司主体ID，一次最多操作1个 |

# 应答字段

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| code | number | 返回码,详见 [【附录-返回码】](https://open.oceanengine.com/labels/7/docs/1696710760866831) |
| message | string | 返回信息,详见 [【附录-返回码】](https://open.oceanengine.com/labels/7/docs/1696710760866831) |
| data | json | json返回值 |
| error\_list | object[] | 共享失败列表，列表为空则代表全部共享成功 |
| share\_mode | string | 共享类型 允许值：`PART` 指定账户共享、`BP_ALL_ACCOUNTS`旧版巨量引擎工作台内所有账户共享、`COMPANY_ALL_ACCOUNTS` 公司主体内所有账户共享    共享类型为`PART`，读取account\_infos；  共享类型为`BP_ALL_ACCOUNTS`，读取all\_account\_by\_bp，即表示该业务线下的全量账号；  共享类型为`COMPANY_ALL_ACCOUNTS`，读取all\_account\_by\_company |
| error\_message | string | 共享失败原因 |
| account\_info | object | 共享账号信息 |
| account\_type | string | 可选值:   * `AD` 营销 * `BP` 旧版巨量引擎工作台 |
| account\_id | number | 账号ID |
| all\_accounts\_by\_bp | string | 旧版巨量引擎工作台组织内业务线 可选值:   * `AD` 营销 |
| all\_accounts\_by\_company | object | 主体信息 |
| account\_type | string | 可选值:   * `AD` 营销 |
| company\_id | number | 公司主体ID |
| request\_id | string | 请求日志id |
