### 概要

#### 含义

> 回调地址是一个用户自定义的链接地址，用户授权完成后，Marketing-API会并将授权相关的信息和state作为参数拼接至该回调地址，并进行跳转。

#### 使用人群

* 如果您是业务人员，在填写回调地址前，需要与内部技术人员沟通确定填写的地址。
* 回调地址用于处理授权码的信息，只有整个流程畅通才可以顺利进行授权管理，所以需要技术人员进行相关业务开发，所以务必正确填写。

#### 形式

> 具体形式请与技术人员沟通自定义选择。

* 后端GET接口

* 将授权信息作为参数直接传递给指定的后端接口，由后端进行处理。
* 适用场景：仅后端逻辑应用，只需要处理token，客户授权完成后无需其他操作。

* 前端界面

* 由前端读取URL中的参数传递给后台做进一步处理。
* 适用场景：搭建了自定义的投放系统，客户授权后需要进行页面的操作。

* 作用

> 在客户授权成功后，会生成auth\_code（该字段为换取token的凭证，通过“[获取Access Token](https://open.oceanengine.com/labels/7/docs/1696710505596940)”接口可换取接口调用凭证access-token），该参数将和state一起传递给回调地址，进行程序化的统一处理。

### 回调地址使用示例

#### 后端GET接口

##### 接口定义

\* URL：  
\* <https://your.server.domain/oauth2/callback>/  
\* **入参**

| 字段 | 类型 | 是否必填 | 含义 |
| --- | --- | --- | --- |
| auth\_code | string | 是 | 授权码 用于换取Access-Token，可作为“[获取Access Token](https://open.oceanengine.com/labels/7/docs/1696710505596940)”接口的请求参数进行调用获取访问凭证 |
| state | string | 是 | 拼接授权链接时自定义拼装的参数，回调时原样返回 一些常见用法： 1. 校验是否是指定的授权（合理性） 2. 特殊逻辑处理（指定的客户需要根据一些参数进行特殊的处理，state=need\_transfer） 3. 存储指定信息（例如希望给客户存储公司信息，在引导用户授权拼接授权url时设置state=company\_name） |

def get_access_token_by_auth_code(auth_code):
    """
    auth_code换取access-token详见https://ad.oceanengine.com/openapi/doc/index.html?id=1696710505596940
    :param auth_code:
    :return:
    """
    import requests
    open_api_url_prefix = "https://ad.oceanengine.com/open_api/"
    uri = "oauth2/access_token/"
    url = open_api_url_prefix + uri
    data = {
        "app_id": APP_ID,
        "secret": APP_SECRET,
        "grant_type": "auth_code",
        "auth_code": auth_code
    }
    rsp = requests.post(url, json=data)
    rsp_data = rsp.json()
    save_oauth_to_db(rsp_data)    # 将access_token等信息进行存储
    return
