# FastAPI + React 日常使用说明

## 入口

- 前端：`http://127.0.0.1:5180/`
- 后端：`http://127.0.0.1:8007/api`
- Streamlit：旧版保留入口，React 验收完成前不删除，不作为日常主入口继续增强。

## 日常顺序

1. 先看首页数据看板，确认产品级实时账户、项目和指标。点点英雄首页口径是账户名包含“点点英雄”且今日有消耗的全量账户。
2. 再看每日自动化健康看板，确认启用定时任务的调度结果和业务结果；这个页面只读本地配置和 `data/runs` 产物，不运行任务。
3. 在产品自动化配置页维护产品基础配置、允许创建账户名单、自动化 dry-run 和 AI 创建模板草稿。
4. 在产品账户库维护账户归属，只有明确选中的账户才参与创建计划。
5. 在投放建议工作台完成“同步数据并重算建议 -> 查看扩量机会、项目管理建议和只读诊断 -> 选择扩量机会生成创建计划预览并跳转创建计划页确认，或选择项目管理建议生成项目管理配置并跳转项目管理页确认”。点点英雄建议页只看“点点英雄-微小-郭靖”且今日有消耗的账户。
6. 在创建计划页完成“生成新计划 -> 执行预览 -> 输入确认 -> 真实执行 -> 进度 -> 结果复盘”。
7. 在项目管理页完成“筛选 -> 生成动作配置 -> 执行预览 -> 输入确认 -> 真实执行 -> 结果复盘”。
8. 在账户备注和落地页管理页完成对应页面内预览、确认、进度和结果复盘。
9. 任务中心只用于历史任务追踪和高级日志查看；正常业务结果优先看发起页面。
10. 操作日志用于审计每次前端动作，主视图看业务内容、状态、触发人和结果摘要。
11. 结果中心用于按业务类型回看最近一次结果，默认看中文摘要和明细表。

## 高风险操作规则

- 不直接阅读原始 JSON 做业务判断，先看中文摘要和明细表。
- 不从 React 或 FastAPI 绕过固定脚本执行真实业务动作。
- 删除项目、账户备注、落地页管理、真实创建都必须走确认组件。
- 投放建议工作台里的扩量机会只生成创建计划预览，不直接创建项目。
- 投放建议工作台里的项目管理建议只生成项目管理配置，不直接执行删除、暂停、预算、出价或时段动作。
- 投放建议工作台里的观察、诊断、继续跑等只读诊断不能生成动作配置。
- 首页和建议页只消费已有实时巡检结果，不改自动巡检调度；缺少匹配实时快照时不能用历史数据或其它口径冒充。
- 每日自动化健康看板只读展示调度和业务产物状态；调度脚本退出码失败、业务产物 `ok=false`、某个产品或范围失败，都应该视为需关注。
- AI 创建模板草稿转正只写本地 `configs/create-modes`，不调用平台接口，也不生成或执行创建计划。
- 如果摘要和目标不一致，停止执行，回到配置或计划生成环节修正。

## 空状态和错误状态

- 结果中心没有找到对应结果时，会显示中文空状态，不再把 404 当成业务结果。
- 未知结果类型会显示“结果类型不可用”，需要回到结果类型目录选择。
- 任务失败时先看发起页面和任务中心的中文摘要；需要排查脚本输出时，再展开任务中心高级日志。
- 任何页面出现阻塞原因时，先处理阻塞原因，不要直接执行固定脚本。

## 切换验收

进入系统设置页查看“React 替换验收清单”。当清单满足且日常链路回归通过后，再封存 Streamlit。
